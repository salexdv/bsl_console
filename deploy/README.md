# BSL Console - Руководство по развертыванию на Cloudflare Pages

## Подготовка к публикации

Директория `deploy` содержит все необходимые файлы для публикации на Cloudflare Pages. Были внесены следующие оптимизации:

1. Настроена работа веб-воркеров Monaco Editor
2. Добавлены метаданные и манифест для оптимизации производительности
3. Оптимизированы заголовки кэширования для статических ресурсов
4. Добавлены правила перенаправления для SPA-режима

## Развертывание на Cloudflare Pages

### Вариант 1: Через веб-интерфейс Cloudflare

1. Войдите в панель управления Cloudflare (https://dash.cloudflare.com/)
2. Перейдите в раздел "Pages"
3. Нажмите "Create a project" → "Direct Upload"
4. Загрузите содержимое папки `deploy`
5. После завершения загрузки, проект будет доступен по URL-адресу, предоставленному Cloudflare

### Вариант 2: Через Wrangler CLI

1. Установите Wrangler CLI: `npm install -g wrangler`
2. Авторизуйтесь в Cloudflare: `wrangler login`
3. Перейдите в директорию `deploy`
4. Выполните команду: `wrangler pages publish .`
5. После публикации, URL-адрес будет выведен в консоли

## Настройка пользовательского домена

1. В панели управления Cloudflare Pages выберите свой проект
2. Перейдите в раздел "Custom domains"
3. Добавьте свой домен и следуйте инструкциям для настройки DNS

## Проверка работоспособности

После развертывания убедитесь, что:

- Monaco Editor корректно загружается
- Работает подсветка синтаксиса BSL
- Правильно работают все функции редактора

## Структура проекта

- `index.html` - основной HTML-файл
- `monaco-fix.js` - исправления для корректной работы Monaco Editor
- `vs/` - директория с файлами Monaco Editor
- `_headers` - настройки HTTP-заголовков для Cloudflare
- `_redirects` - правила перенаправления
- Остальные JS-файлы - компоненты BSL Console

## Диагностика проблем

Если возникают ошибки с загрузкой Monaco Editor:

1. Проверьте консоль браузера на наличие ошибок
2. Убедитесь, что все пути к файлам корректны
3. Проверьте, что веб-воркеры загружаются правильно

При необходимости отладки используйте скрипт `debug_syntax.js`.
