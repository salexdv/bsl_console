# Событие *EVENT_ON_HELP_READY*

## Назначение

Событие отправляется после успешного завершения `parseHelp`, если загружен пакет объектной модели
`shcntx_*.hbk`, либо профильный пакет режима `shquery_*.hbk` (язык запросов) или `dcsui_*.hbk`
(система компоновки данных). К этому моменту дерево содержания, индекс имён и полнотекстовый индекс
уже готовы.

Событие возникает после каждой успешной загрузки или атомарной замены пакетов `shcntx`, `shquery`,
`dcsui`. Загрузка `shlang`, ошибка разбора и сохранение прежнего пакета событие не создают.

## Параметры

Событие вызывается с объектом-параметром, содержащим поле `kind` — вид загруженного пакета:

```js
window.sendEvent('EVENT_ON_HELP_READY', { kind: 'context' | 'query' | 'dcs' });
```

Поле `kind` принимает одно из строковых значений:

* **`context`** — загружен `shcntx_*.hbk` (объектная модель, режимы `bsl`/`xml`);
* **`query`** — загружен `shquery_*.hbk` (язык запросов, режим `bsl_query`);
* **`dcs`** — загружен `dcsui_*.hbk` (система компоновки данных, режим `dcs_query`).

Другие значения не предусмотрены. Полей кроме `kind` в payload нет.
