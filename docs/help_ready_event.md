# Событие *EVENT_ON_HELP_READY*

## Назначение

Событие отправляется после успешного завершения `parseHelp`, если загружен пакет объектной модели
`shcntx_*.hbk`. К этому моменту дерево содержания, индекс имён и полнотекстовый индекс уже готовы.

Событие возникает после каждой успешной загрузки или атомарной замены `shcntx`. Загрузка `shlang`,
ошибка разбора и сохранение прежнего пакета событие не создают.

## Параметры

Событие вызывается без параметров:

```js
window.sendEvent('EVENT_ON_HELP_READY');
```
