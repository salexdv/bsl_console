# Функция *hideBlocks*

## Назначение функции

Сворачивает переданные диапазоны строк в обычном редакторе. В режиме сравнения функция ничего
не изменяет.

## Параметры функции

* **blocks** — массив диапазонов:
  * **startLineNumber** — номер первой скрываемой строки;
  * **endLineNumber** — номер последней скрываемой строки.

Диапазоны ограничиваются границами модели. Некорректные диапазоны и диапазоны с повторяющейся
начальной строкой пропускаются.

```javascript
hideBlocks([
  { startLineNumber: 1, endLineNumber: 18 },
  { startLineNumber: 173, endLineNumber: 190 }
]);
```

Каждая область получает виджет раскрытия. После раскрытия её можно снова свернуть значком на поле
редактора. Собственные области не заменяют штатное сворачивание Monaco.
