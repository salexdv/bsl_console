# Функции вкладок

## `createTab`

Создаёт отдельную вкладку с редактором и делает её текущей. Все документные функции (`getText`,
`setText`, `setLanguageMode`, `compare` и другие) после этого работают с новой вкладкой.

```javascript
createTab('Модуль объекта', 'Процедура ПриЗаписи()\nКонецПроцедуры');

createTab('Запрос', 'ВЫБРАТЬ 1', {
  language: 'bsl_query',
  readOnly: true
});

// При вызове из 1С параметры передаются JSON-строкой.
createTab('Запрос из 1С', 'ВЫБРАТЬ 1', '{"language":"bsl_query","readOnly":true}');
```

Параметры:

- `title` — название вкладки;
- `text` — начальный текст редактора;
- `options` — необязательный объект или JSON-строка с объектом:
  - `language` — режим языка, по умолчанию `bsl`;
  - `readOnly` — режим «Только просмотр», по умолчанию `false`.

Если строка содержит некорректный JSON или JSON-значение не является объектом, вкладка создаётся
с настройками по умолчанию. Неизвестные поля объекта игнорируются.

Каждый вызов создаёт новую вкладку, даже если такое название уже существует. Установка начального текста
не генерирует `EVENT_CONTENT_CHANGED`.

## `closeCurrentTab`

Закрывает текущую вкладку:

```javascript
closeCurrentTab();
```

После закрытия выбирается последняя ранее активная вкладка. Если вкладка была единственной, вместо неё
остаётся пустая редактируемая BSL-вкладка «Основная».

Подтверждение закрытия включается общей опцией:

```javascript
setOption('confirmTabClose', true);
```

При включённой опции подтверждение показывается и для `closeCurrentTab()`, и для крестика вкладки.

## `getCurrentTab`

Возвращает название и нулевой индекс текущей вкладки в том же формате, что и параметры
`EVENT_TAB_CHANGED`:

```javascript
const currentTab = getCurrentTab();
// { title: 'Запрос', index: 1 }
```

До инициализации контроллера вкладок функция возвращает `null`.
