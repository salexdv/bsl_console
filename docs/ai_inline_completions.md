# AI inline-подсказки через 1С

## Назначение

Редактор определяет момент запроса и отображает результат, а 1С выполняет сетевой вызов AI-провайдера.
URL, ключи, prompt и полный ответ провайдера не хранятся в JavaScript редактора.

Механизм работает для режимов `bsl`, `bsl_query` и `dcs_query` и по умолчанию выключен:

```javascript
setOption('generateAIInlineCompletionEvent', true);
```

После пользовательской правки редактор ждёт `aiInlineCompletionDebounceMs` и создаёт
`EVENT_AI_INLINE_COMPLETION_REQUEST`. Вызов `triggerInlineSuggestions()` создаёт явный запрос без задержки.
Перемещение курсора отменяет текущий запрос, но само по себе новый AI-запрос не создаёт.

## EVENT_AI_INLINE_COMPLETION_REQUEST

```json
{
  "protocolVersion": 1,
  "requestId": 17,
  "modelVersionId": 42,
  "modelUri": "inmemory://model/1",
  "languageId": "bsl",
  "position": {
    "lineNumber": 12,
    "column": 18
  },
  "triggerKind": "automatic",
  "triggerCharacter": "=",
  "context": {
    "prefix": "...",
    "suffix": "...",
    "prefixTruncated": true,
    "suffixTruncated": false
  }
}
```

`prefix` и `suffix` — снимок модели относительно позиции курсора. Их длина ограничивается опциями
`aiInlineCompletionMaxPrefixChars` и `aiInlineCompletionMaxSuffixChars`. Пробелы и переводы строк
сохраняются. `triggerKind` принимает значения `automatic` и `explicit`.

## Передача результата

После завершения сетевого запроса 1С вызывает функцию редактора:

```javascript
resolveAIInlineCompletion(17, [
  ' = Новый Запрос();\nЗапрос.Текст = "ВЫБРАТЬ";'
]);
```

Из 1С удобнее передавать массив как JSON-строку:

```javascript
resolveAIInlineCompletion(17, '[" = Новый Запрос();"]');
```

Функция возвращает:

* `true` — запрос найден и завершён, в том числе пустым массивом;
* `false` — запрос уже отменён, просрочен или потерял актуальность;
* `{ errorDescription }` — передано невалидное значение.

Редактор показывает только ответ для той же модели, версии и позиции. Запоздавший результат никогда не
переносится в новую позицию. Пустой массив следует передавать при отсутствии подсказки или ошибке AI.

## EVENT_AI_INLINE_COMPLETION_CANCEL

Если уже отправленный запрос перестал быть актуальным, редактор генерирует:

```json
{
  "protocolVersion": 1,
  "requestId": 17,
  "reason": "superseded"
}
```

Возможные причины: `superseded`, `cursorChanged`, `hidden`, `disabled`, `timeout`, `disposed`.
Обработка события на стороне 1С необязательна, но позволяет прервать HTTP-запрос и не расходовать лимит
провайдера. Если отмена произошла во время debounce, событие не создаётся, поскольку 1С ещё не получила
запрос.

## Схема обработчика 1С

Ниже приведён псевдокод: конкретный способ фонового HTTP-вызова зависит от версии платформы и обвязки формы.

```bsl
Если ДанныеСобытия.event = "EVENT_AI_INLINE_COMPLETION_REQUEST" Тогда
    ЗапросAI = ДанныеСобытия.params;
    ЗапуститьАсинхронныйЗапросAI(ЗапросAI, Новый ОписаниеОповещения(
        "ПослеПолученияAIПодсказки", ЭтотОбъект, ЗапросAI.requestId));

ИначеЕсли ДанныеСобытия.event = "EVENT_AI_INLINE_COMPLETION_CANCEL" Тогда
    ОтменитьЗапросAI(ДанныеСобытия.params.requestId);
КонецЕсли;

Процедура ПослеПолученияAIПодсказки(Результат, ИдентификаторЗапроса) Экспорт
    ОкноРедактора = Элементы.ПолеHTMLДокумента.Документ.defaultView;
    ОкноРедактора.resolveAIInlineCompletion(
        ИдентификаторЗапроса,
        СериализоватьМассивСтрокВJSON(Результат));
КонецПроцедуры
```

Сетевой вызов не должен блокировать UI-поток. Токен провайдера не следует передавать в редактор, события или
журнал регистрации.
