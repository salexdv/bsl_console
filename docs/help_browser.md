# Встроенный браузер синтакс-помощника 1С

Браузер принимает штатные файлы платформы `shcntx_*.hbk` (объектная модель) и `shlang_*.hbk`
(встроенный язык). Файлы и построенные индексы живут только в текущей сессии страницы и не входят
в сборку редактора.

## Загрузка

В обычном браузере HBK можно выбрать в компактной панели **Справка 1С** над редактором. Она скрыта
по умолчанию и показывается вызовом `window.showHelpLoader()`. Разрешён одновременный выбор нескольких
файлов; они загружаются последовательно, а результат каждого файла показывается в строке состояния.

```js
const result = await window.parseHelp(file);
// { ok: true, kind: "context", pages: 25503, error: null }
```

Аргумент может быть `Blob`, `File`, чистой Base64-строкой или Base64 data URL. Base64 декодируется
в worker и не блокирует основной поток страницы:

```js
const result = await window.parseHelp(base64);
```

Небольшую строку можно передать напрямую после загрузки HTML-документа:

```bsl
Окно = Элементы.ПолеHTMLДокумента.Документ.defaultView;
Окно.parseHelp(Base64Строка(Новый ДвоичныеДанные(ПутьКHBK)));
Окно.showHelp();
```

Большие HBK следует передавать порциями через универсальный
[`Base64-мост`](base64_transfer.md), после чего вызывать `parseHelp()` без аргументов.
Если загружаются оба пакета, `parseHelp()` нужно вызвать после завершения каждой из двух передач.
Проверка и декодирование порций выполняются в worker; ошибки данных возвращаются из соответствующего
`parseHelp()` обычным объектом результата.

Promise всегда разрешается объектом:

| Поле | Описание |
| --- | --- |
| `ok` | пакет полностью прочитан, дерево и индексы готовы |
| `kind` | `context`, `language` или `null` при ошибке |
| `pages` | количество проиндексированных HTML-страниц |
| `error` | текст ошибки или `null` |

Для большого `shcntx` сначала читаются оглавление и центральный каталог ZIP. После этого дерево,
предметный индекс и открытие отдельных статей уже доступны, а полная CRC-проверка и полнотекстовый
индекс достраиваются порциями в worker. `parseHelp()` по-прежнему завершается только после полной
проверки. Если поздняя проверка обнаруживает повреждение, новый кандидат отбрасывается, а предыдущий
успешно загруженный пакет восстанавливается.

Сравнение eager, ленивой загрузки по оглавлению и штатного `IndexPackBlock` приведено в
[`specs/help-browser/benchmark.md`](../specs/help-browser/benchmark.md). На пакетах 8.3.25–8.5
ленивая загрузка по оглавлению дала навигацию в среднем за 458 мс вместо 2971 мс; поэтому она
используется по умолчанию. Повторить замеры можно командами `npm run benchmark:help -- <hbk...>` и,
после `npm run build:headless`, `npm run benchmark:help:chrome -- <hbk...>`.

Пакеты можно передавать в любом порядке. Разные виды объединяются, повторная успешная загрузка
атомарно заменяет только пакет того же вида. Если новый файл повреждён, прежняя успешно загруженная
версия остаётся доступна.

## Открытие

```js
window.showHelp();
```

Для показа скрытой по умолчанию панели ручного выбора `.hbk`:

```js
window.showHelpLoader();
```

Панель открывается сразу справа от Monaco, в том числе во время загрузки, и показывает текущее
состояние. Начальная ширина составляет 30%; внешний вертикальный разделитель меняет ширину панели.
Навигация расположена сверху, статья снизу, их высоту меняет внутренний горизонтальный разделитель.
Выбранные размеры, вкладка и статья сохраняются между открытиями в текущей сессии.

`CTRL+F1` в обычном редакторе, режиме запроса и на активной стороне режима сравнения получает слово
под курсором через Monaco. Если справка полностью готова, действие открывает вкладку «Индекс» и
первую найденную статью; при отсутствии слова панель открывается без изменения вкладки и статьи.
Во время загрузки, при ошибке или без HBK сочетание не открывает панель и не сохраняет отложенный
поиск. Опция [`generateGetHelpEvent`](set_option.md) позволяет независимо отправлять в 1С событие
[`EVENT_ON_GET_HELP`](get_help_event.md). Кнопка закрытия или `Esc` возвращает фокус в редактор и
восстанавливает его размер.

После успешной загрузки или замены `shcntx` редактор отправляет в 1С событие
[`EVENT_ON_HELP_READY`](help_ready_event.md). Загрузка `shlang` и ошибки разбора это событие не создают.

Вкладки панели:

* **Содержание** — ленивое дерево обоих загруженных пакетов;
* **Индекс** — регистронезависимый prefix-поиск по заголовкам; серым в скобках показывается компактный
  путь владельца, группы и статьи;
* **Поиск** — полнотекстовый AND-поиск, где `е` и `ё` эквивалентны.

Поиск показывает не более 1000 результатов, сохраняя полное число совпадений. Слова текущего запроса
подсвечиваются в открытой статье. Внутренние `v8help://` и относительные ссылки HBK открываются в той
же панели независимо от того, раскрыт ли целевой узел содержания. Якоря прокручивают статью к
указанному разделу, HTTP(S) открываются в отдельном безопасном окне.

В содержании пустые служебные разделы HBK отображаются как «Свойства», «Методы», «Конструкторы»,
«События», «Поля», «Параметры» или «Параметры формы», когда тип раздела однозначно определяется по
его непосредственным страницам.
