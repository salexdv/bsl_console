# Событие *EVENT_ON_HELP_PREPARED*

## Назначение

Ранний сигнал готовности справки. Событие отправляется на фазе `prepared` разбора HBK, когда
воркер уже построил оглавление и префиксный индекс по заголовкам из TOC и опубликовал
provisional-пакет в UI. В этот момент вкладки «Содержание» и «Индекс» пригодны для поиска —
обычно через 4-5 секунд после `parseHelp`. Полнотекстовая индексация всех HTML-страниц ещё
продолжается; её завершение обозначается отдельным событием
[`EVENT_ON_HELP_READY`](help_ready_event.md).

Событие возникает после каждой успешной загрузки или атомарной замены пакетов `shcntx`, `shquery`,
`dcsui`. Загрузка `shlang`, ошибка разбора и сохранение прежнего пакета событие не создают.

> ⚠️ **Orphan PREPARED.** `EVENT_ON_HELP_PREPARED` **не гарантирует** последующего
> `EVENT_ON_HELP_READY`. Если после фазы `prepared` полнотекстовая индексация падает (откат
> provisional-кандидата или ошибка worker'а), READY не наступит. 1С должно толерировать
> «PREPARED без READY» и считать PREPARED вероятной, но не окончательной готовностью.

## Параметры

Событие вызывается с объектом-параметром, содержащим поле `kind` — вид загруженного пакета:

```js
window.sendEvent('EVENT_ON_HELP_PREPARED', { kind: 'context' | 'query' | 'dcs' });
```

Поле `kind` принимает одно из строковых значений:

* **`context`** — загружен `shcntx_*.hbk` (объектная модель, режимы `bsl`/`xml`);
* **`query`** — загружен `shquery_*.hbk` (язык запросов, режим `bsl_query`);
* **`dcs`** — загружен `dcsui_*.hbk` (система компоновки данных, режим `dcs_query`).

Другие значения не предусмотрены. Полей кроме `kind` в payload нет.

## Связь с `EVENT_ON_HELP_READY`

| Событие | Фаза | Что готово |
| --- | --- | --- |
| `EVENT_ON_HELP_PREPARED` | `prepared` | оглавление, префиксный индекс заголовков (вкладка «Индекс»), provisional-пакет в UI |
| `EVENT_ON_HELP_READY` | `parsed` | дополнительно — полнотекстовый индекс всех HTML-страниц (вкладка «Поиск») |

Для одной операции `parseHelp` PREPARED всегда предшествует READY (если READY наступает). При
повторной загрузке того же вида оба события отправляются снова.
