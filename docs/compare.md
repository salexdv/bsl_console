# Функция *compare*
## Назначение функции
Функция включает/выключает режим сравнения текстов (DiffEditor)

Отображением значка отмены изменений и скрытием неизмененных областей можно управлять опциями
`renderMarginRevertIcon` и `hideUnchangedRegions` в секции
[«Управление режимом сравнения»](set_option.md#управление-режимом-сравнения).

## Управление неизмененными блоками

Функции `hideUnchangedBlocks()` и `showUnchangedBlocks()` соответственно скрывают и показывают
неизмененные блоки. Они работают только в режиме сравнения и устанавливают опцию
[`hideUnchangedRegions`](set_option.md#управление-режимом-сравнения) через функцию `setOption`:

```javascript
// Скрыть неизмененные блоки
hideUnchangedBlocks();

// Показать неизмененные блоки
showUnchangedBlocks();
```

При вызове вне режима сравнения функции ничего не делают и не изменяют сохраненное значение опции.

## Параметры функции
* **text** - *string*, текст для сравнения с текущим текстом редактора
* **sideBySide** - *boolean*, двусторонний/построчный режим сравнения
* **highlight** - *boolean*, включена/выключена подсветка синтаксиса
* **markLines** - *boolean*, включена/выключена индикация (пиктограмма) для измененных строк. Необязательный параметр. Значение по умолчанию: true

**Вызов функции без параметров отключает режим сравнения и наоборот**

## Пример вызова
```javascript
// Включение двустороннего режима сравнения с подсветкой синтаксиса
compare(`ВЫБРАТЬ
	Номенклатура.Ссылка КАК Ссылка,
	Номенклатура.Артикул КАК Артикул,
	Номенклатура.ЕдиницаИзмерения КАК ЕдиницаИзмерения
ПОМЕСТИТЬ втТовары
ИЗ
	Справочник.Номенклатура КАК Номенклатура
ГДЕ
	Номенклатура.ВидНоменклатуры = &Товары
;

////////////////////////////////////////////////////////////////////////////////
ВЫБРАТЬ
	втТовары.Ссылка КАК Ссылка,
	втТовары.Артикул КАК Артикул,
	втТовары.ЕдиницаИзмерения КАК ЕдиницаИзмерения
ИЗ
	втТовары КАК втТовары
`, true, true);

// Отключение режима сравнения
compare();
```

## Влючение/отключение двусторонеего сравнения

```javascript
// Включение двустороннего режима сравнения
setDiffSideBySideMode(true);

// Отключение двустороннего режима сравнения
setDiffSideBySideMode(true);
```
