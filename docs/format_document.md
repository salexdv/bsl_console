# Функция *formatDocument*

## Назначение функции

Форматирует выделенный фрагмент BSL-кода или весь документ, если выделение пустое. Базовое
форматирование исправляет отступы и удаляет хвостовые пробелы. Дополнительные преобразования
включены по умолчанию, действуют только для текущего вызова и не сохраняются в настройках редактора.

## Параметры функции

* **optionsJSON** - необязательная JSON-строка объекта с boolean-опциями форматирования. Все опции,
  включая не указанные в переданном объекте, по умолчанию равны `true`.

| Опция | Назначение |
| --- | --- |
| `formatCanonicalKeywords` | Приводит ключевые слова BSL к регистру из словаря языка, а известное имя класса после `Новый`/`New` — к регистру из `bslGlobals.classes` |
| `formatCanonicalPlatformNames` | Приводит к каноническому регистру известные глобальные функции, типы после `Новый` и методы платформы |
| `formatSplitStatements` | Переносит на отдельные строки операторы, разделённые `;` вне строк, комментариев и скобок |
| `formatSpaceAfterComma` | Удаляет пробел перед запятой и добавляет один пробел после неё в коде |
| `formatAlignAssignments` | Выравнивает `=` в непрерывных группах простых присваиваний с одинаковым отступом |
| `formatJoinThen` | Объединяет однострочные заголовки `Если`/`ИначеЕсли` с `Тогда`, заголовки `Пока`/`Для`/`Для Каждого` с `Цикл` и их английские синонимы; выносит `КонецЕсли`/`КонецЦикла` на отдельные строки |
| `formatBlankLinesAroundBlocks` | Оставляет ровно одну пустую строку вокруг объявлений функций и процедур, условий, циклов, попыток, веток и их окончаний |

`formatBlankLinesAroundBlocks` не зависит от `formatJoinThen`: отдельные `Тогда`/`Then` и
`Цикл`/`Do` считаются частью предшествующего заголовка. В начале и конце форматируемого документа
или выделения новые пустые строки не создаются. Пустые строки между обычными операторами
сохраняются, если они не прилегают к структурной границе. Аннотации и документирующие комментарии
перед функцией или процедурой остаются связанными с объявлением.

Неизвестные поля объекта игнорируются. Некорректный JSON, значение не в виде объекта или
распознанная опция не типа boolean приводят к возврату объекта `{ errorDescription }` без изменения
текста. Передача готового JavaScript-объекта вместо JSON-строки не поддерживается.

## Пример вызова

```javascript
// Все дополнительные преобразования включены
formatDocument();
formatDocument('{}');

// Выборочное отключение преобразований для одного вызова
formatDocument(JSON.stringify({
    formatAlignAssignments: false,
    formatBlankLinesAroundBlocks: false
}));

// Только базовые отступы и удаление хвостовых пробелов
formatDocument(JSON.stringify({
    formatCanonicalKeywords: false,
    formatCanonicalPlatformNames: false,
    formatSplitStatements: false,
    formatSpaceAfterComma: false,
    formatAlignAssignments: false,
    formatJoinThen: false,
    formatBlankLinesAroundBlocks: false
}));
```

Следующий вызов `formatDocument()` не наследует явно переданные значения и снова включает все
опции. Неизвестные поля объекта игнорируются.

## Разделение операторов одной строки

Опция `formatSplitStatements` переносит на отдельные строки несколько операторов, разделённых
верхнеуровневой точкой с запятой. Точки с запятой внутри строковых литералов не учитываются.

```javascript
formatDocument(JSON.stringify({
    formatCanonicalKeywords: false,
    formatCanonicalPlatformNames: false,
    formatSplitStatements: true,
    formatSpaceAfterComma: false,
    formatAlignAssignments: false,
    formatJoinThen: false,
    formatBlankLinesAroundBlocks: false
}));
```

До форматирования:

```bsl
перем1 = 1;перем2="А;Б";
перем3 = 1; сообщить("Привет!; Как дела?");
```

После форматирования:

```bsl
перем1 = 1;
перем2="А;Б";
перем3 = 1;
сообщить("Привет!; Как дела?");
```
