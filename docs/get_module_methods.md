# Функция *getModuleMethods*

## Назначение функции

Функция возвращает сведения обо всех процедурах и функциях текущего BSL-модуля. Методы следуют в порядке объявления в тексте.

Для интерактивного перехода к методу используется встроенное окно Monaco **Go to Symbol**. Оно открывается сочетанием `CTRL+ALT+P` или стандартным сочетанием `CTRL+SHIFT+O`, поддерживает фильтрацию по имени и выбор через `Enter` или мышью.

## Параметры функции

Функция не принимает параметров.

## Возвращаемое значение

Функция возвращает JSON-строку с массивом объектов. Для каждого метода доступны поля:

| Поле | Тип | Описание |
| --- | --- | --- |
| `name` | Строка | Имя процедуры или функции |
| `line` | Число | Номер строки объявления, начиная с единицы |
| `type` | Строка | `procedure` для процедуры или `function` для функции |
| `isExport` | Булево | Признак ключевого слова `Экспорт` или `Export` |
| `hasParameters` | Булево | Признак наличия параметров |
| `parameters` | Массив | Описания параметров в порядке объявления |

Описание параметра содержит поля:

| Поле | Тип | Описание |
| --- | --- | --- |
| `name` | Строка | Имя параметра |
| `byValue` | Булево | `true`, если указан модификатор `Знач` или `Val`; `false` означает передачу по ссылке |
| `hasDefaultValue` | Булево | Признак наличия значения по умолчанию |
| `defaultValue` | Строка или `null` | Исходный текст значения после `=` без внешних пробелов; `null`, если значение не задано |

Для модуля без процедур и функций возвращается строка `[]`.

## Пример

Исходный модуль:

```bsl
Функция ЭтоЧисло(Знач ПроверяемоеЗначение, Режим = Ложь) Экспорт
	// Какой-то код
КонецФункции
```

Вызов:

```javascript
const methods = JSON.parse(getModuleMethods());
```

Результат после разбора JSON:

```json
[
  {
    "name": "ЭтоЧисло",
    "line": 1,
    "type": "function",
    "isExport": true,
    "hasParameters": true,
    "parameters": [
      {
        "name": "ПроверяемоеЗначение",
        "byValue": true,
        "hasDefaultValue": false,
        "defaultValue": null
      },
      {
        "name": "Режим",
        "byValue": false,
        "hasDefaultValue": true,
        "defaultValue": "Ложь"
      }
    ]
  }
]
```
