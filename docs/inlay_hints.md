# Функции *setInlayHints* / *clearInlayHints*

## Назначение функций

Показывают инлей-хинты — короткие текстовые подсказки, которые выводятся прямо в строках кода,
не меняя текст модуля: `getText()` их не возвращает, поиск/замена, форматирование и подсветка
синтаксиса их не затрагивают. Так можно показать, например, выведенный тип переменной рядом с
присваиванием или результат собственной диагностики.

Хинты переживают прокрутку и правки соседнего текста — якорь подсказки следует за кодом. Состав хинтов
не пересчитывается автоматически: при изменении текста 1С может прислать обновленный набор
повторным вызовом `setInlayHints` (например, по [событию](modification_event.md) изменения).
Исключение — [тултипы параметров запроса](query_params_tooltips.md): они показываются через
`setQueryParamsTooltips`, занимают набор целиком и пересчитываются автоматически при изменении текста.

Клик по хинту генерирует событие `EVENT_ON_INLAY_HINT_CLICK` с полями хинта (`id`, `line`,
`column`, `text`) и значением `event_params`. **Кликабельный — только хинт с заданным
`event_params`** (отсутствует или `null`): у остальных клики проходят сквозь в редактор как
обычно.

`clearInlayHints` убирает все хинты текущей вкладки. Набор хинтов хранится на вкладке и
восстанавливается при переключении.

## Параметры функции setInlayHints

* **hints** - *Array&lt;Object&gt; | string*, массив хинтов или JSON-строка с ним. Поля хинта:
  * **line** - *number*, строка (с единицы), в которой выводится подсказка;
  * **column** - *number*, колонка (с единицы), **после** которой выводится текст — для позиции
    в конце строки передайте длину строки + 1;
  * **text** - *string*, однострочный текст подсказки (переводы строк заменяются пробелом);
  * **id** - *string | number*, необязательный идентификатор, возвращаемый событием клика;
  * **event_params** - *произвольное значение*, необязательные параметры, прокидываемые в 1С
    с событием `EVENT_ON_INLAY_HINT_CLICK` без изменений. Хинт с незаданным `event_params`
    (отсутствует или `null`) не кликабельный.

Хинты с позициями за пределами текста и элементы без полей `line`/`column`/`text` пропускаются.
Невалидная JSON-строка возвращает `{errorDescription}` и не меняет текущий набор.

## Пример вызова

```javascript
// Передача JavaScript-массива: первый хинт кликабельный, второй — нет
setInlayHints([
  { line: 1, column: 25, text: ": ТаблицаЗначений", id: 1, event_params: { action: "showType" } },
  { line: 2, column: 22, text: ": СтрокаТаблицыЗначений", id: 2 }
]);

// Передача JSON-строки
setInlayHints('[{"line":1,"column":25,"text":": ТаблицаЗначений","event_params":"open-card"}]');

// Убрать все хинты
clearInlayHints();
```
