# Событие *EVENT_ON_GET_HELP*

## Назначение события

Событие опционально генерируется при нажатии `CTRL+F1` над словом в активном редакторе. Оно
отправляется независимо от того, загружены ли HBK. Если справка текущего языкового режима полностью
готова, после события редактор также выполняет встроенный поиск слова в её индексе.

## Управление событием

За генерацию отвечает опция [`generateGetHelpEvent`](set_option.md). По умолчанию она отключена.

```javascript
setOption('generateGetHelpEvent', true);
setOption('generateGetHelpEvent', false);
```

## Параметры события

Параметры совпадают с [`EVENT_GET_DEFINITION`](get_definition_event.md):

* **word** — слово под курсором;
* **expression** — полное выражение или имя функции;
* **module** — имя общего модуля или пустая строка;
* **class** — имя объекта или пустая строка;
* **line** — номер строки;
* **column** — номер колонки;
* **expression_array** — элементы выражения перед текущим значением.

Если под курсором нет слова, событие не создаётся. Состояния `empty`, `loading` и `error` запрещают
автоматическое открытие панели по `CTRL+F1`; событие при этом по-прежнему отправляется, если опция
включена.
