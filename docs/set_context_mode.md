# Функция *setContextMode*

## Назначение функции

Функция устанавливает текущий контекст редактора, сервер или тонкий клиент. Контекст влияет на доступность подсказок (объекты метаданных, конструкторы, глобальные функции и т.д.)

## Параметры функции

* **mode** - *string*, идентификатор контекста. Может принимать одно из следующих значений:
	* Server - Сервер - будут показываться подсказки, доступные в контексте сервера
	* Client - Клиент - будут показываться подсказки, доступные в контексте тонкого клиента

**По умолчанию контекст редактора не установлен, поэтому показываются все подсказки**

## Пример вызова

```javascript
setContextMode('Server'); // Переключение в режим сервера
setContextMode('Client'); // Переключение в режим тонкого клиента
setContextMode(''); // Отключение фильтра по контексту для подсказок
```
