# Функция *setQueryParamsTooltips*

## Назначение функции

Показывает тултипы фактических значений параметров запроса (`&Параметр`) как
[инлей-хинты](inlay_hints.md) — короткие подсказки сразу после каждого вхождения параметра
в тексте запроса, без изменения самого текста. Работает только в режимах языка запросов
([`setLanguageMode('bsl_query')`](set_language_mode.md)) и языка СКД
(`setLanguageMode('dcs_query')`).

В отличие от `setInlayHints` позиции передавать не нужно: редактор сам находит вхождения
параметров в тексте модели и **пересчитывает набор при каждом изменении текста** — тултип
следует за параметром при вставке/удалении строк выше, исчезает при переименовании или
удалении параметра, появляется у нового вхождения (например, при редактировании запроса).
Повторный вызов из 1С по [событию](modification_event.md) изменения не требуется.

Один параметр, встречающийся несколько раз (части UNION, повторные секции), получает тултип
у каждого вхождения. Граница имени соблюдается: `&Парам` не совпадает с `&Параметр`.

Клик по тултипу с заданным `value` генерирует событие
[`EVENT_ON_INLAY_HINT_CLICK`](inlay_hints.md) с полями `{id, line, column, text}` и значением
`event_params`: `id` — имя параметра, `text` — переданный `label`, `event_params` — переданный
`value` без изменений. Тултип без `value` (отсутствует или `null`) не кликабельный, клики
проходят сквозь в редактор.

## Всплывающая подсказка при наведении

Необязательное поле `tooltip` — *markdown-строка*: при наведении на тултип параметра редактор
показывает её как всплывающую подсказку (штатный markdown-рендерер Monaco с очисткой HTML —
работают выделение `**жирным**`, `` `код` ``, списки, таблицы; ссылки `http/https` кликабельны).
Подсказка появляется у каждого вхождения параметра.

В отличие от кликабельных хинтов `setInlayHints`, у тултипов параметров **нет** штатной
гиперссылки «Выполнить команду (ctrl+click)» во всплывающем окне — вместо неё и показывается
`tooltip`. Клик — обычный, без модификатора: у тултипа с заданным `value` курсор над ним
принимает вид pointer. Если `tooltip` не задан — наведение ничего не показывает (клик при
заданном `value` продолжает работать).

## Набор инлей-хинтов общий с setInlayHints

Тултипы параметров занимают набор инлей-хинтов вкладки целиком:

- повторный вызов `setInlayHints` стирает тултипы параметров и отключает автопересчёт
  до нового вызова `setQueryParamsTooltips`;
- `clearInlayHints()` (или `setQueryParamsTooltips([])`) убирает всё;
- переключение режима редактора из режима запроса/СКД очищает тултипы и запоминающий набор.

## Параметры функции setQueryParamsTooltips

* **params** - *Array&lt;Object&gt; | string*, массив описаний (или JSON-строка с ним). Поля элемента:
  * **param** - *string*, имя параметра без `&` (непустое);
  * **label** - *string*, текст тултипа (непустое, однострочное);
  * **value** - *произвольное значение*, необязательные параметры, прокидываемые в 1С
    с событием `EVENT_ON_INLAY_HINT_CLICK` без изменений. Тултип с незаданным `value`
    (отсутствует или `null`) не кликабельный;
  * **tooltip** - *string*, необязательная markdown-строка всплывающей подсказки при наведении
    (отсутствует или `null` — подсказки нет).

Элементы без обязательных полей `param`/`label` пропускаются; при дубликатах имён побеждает
последний элемент. Параметры, не найденные в тексте запроса, молча игнорируются. Пустой массив
эквивалентен `clearInlayHints()`. Невалидная JSON-строка возвращает `{errorDescription}` и не
меняет текущий набор.

## Пример вызова

```javascript
// Режим языка запросов
setLanguageMode('bsl_query');

setQueryParamsTooltips([
    {
        param: "ИсключаемыйРегистратор",
        label: "Приходная накладная №1 от 12.03.2025",
        value: "e8db7890-6b72-453e-a3c4-ecc721864638",
        tooltip: "**Документ**: [Приходная накладная №1](https://example.local/doc/1) от 12.03.2025"
    },
    {
        param: "ГоловнаяОрганизация",
        label: "ООО Ромашка",
        value: "7fd82080-aedc-46f1-9763-80918dc36b79",
        tooltip: "**ИНН** `7701234567`, КПП `770101001`"
    },
    {
        param: "НачалоГода",
        label: "01.01.2021",
        tooltip: "Начало периода отчёта"
    },
    {
        param: "КонецМесяца",
        label: "31.12.2021 23:59:59"
    }
]);

// Убрать все инлей-хинты, включая тултипы параметров
clearInlayHints();
```
