## Введение

При миграции с Monaco Editor 0.20.0 на версию 0.45.0+, система подсветки синтаксиса требует адаптации из-за изменений в API и внутренней архитектуре Monaco. В этом документе описаны шаги, необходимые для адаптации существующей системы подсветки кода BSL к новой версии Monaco Editor.

## Изменения в API Monaco Editor

Основные изменения в API, влияющие на систему подсветки синтаксиса:

1. **Изменения в системе регистрации языков:**
   - В Monaco 0.45.0+ изменен подход к регистрации языков через `monaco.languages.register()` и `monaco.languages.setMonarchTokensProvider()`
   - Изменена структура и формат определения правил токенизации

2. **Изменения в системе тем:**
   - В новой версии усовершенствован API для работы с темами
   - Изменен способ регистрации и применения цветовых правил к токенам

3. **Изменения в токенизации:**
   - Обновлен механизм токенизации, влияющий на производительность и точность подсветки синтаксиса
   - Добавлены новые возможности для кастомизации токенизации

## Анализ текущей системы подсветки

Текущая система подсветки синтаксиса в BSL Console:

1. **Структура определения языка BSL:**
   - Определен язык `bsl` с набором правил токенизации
   - Используются различные токены для ключевых слов, идентификаторов, строк, чисел и т.д.
   - Дополнительные правила для режима запросов

2. **Система тем:**
   - Поддержка нескольких тем: светлая (white), темная (dark), EDT-стиль (edtWhite, edtDark)
   - Определены правила окраски для различных типов токенов в каждой теме
   - Поддержка специальных стилей для режима запросов (whiteQueryOn, darkQueryOn и т.д.)

3. **Токенизация:**
   - Кастомные правила токенизации для языка BSL
   - Дополнительные правила для SQL-подобных запросов
   - Поддержка операторов, ключевых слов, функций на русском и английском языках

## Шаги адаптации


### 1. Адаптация правил токенизации

Обновите структуру правил токенизации в соответствии с новым форматом:

```javascript
let bsl_language = {
    // Базовые параметры остаются похожими
    id: 'bsl',
    ignoreCase: true,
    
    // Обновить формат токенизатора при необходимости
    tokenizer: {
        root: [
            // Правила токенизации с учетом новых возможностей Monaco
            [/\/\/.*$/, 'comment.bsl'],
            // ...другие правила
        ],
        // ...другие состояния токенизатора
    }
};
```

### 2. Обновление системы тем

Адаптируйте систему тем к новому API:

```javascript
[x]
// Регистрация темы для BSL (новый подход)
monaco.editor.defineTheme('bsl-dark', {
    base: 'vs-dark',
    inherit: true,
    rules: [
        { token: 'commentbsl', foreground: '6A9955' },
        { token: 'keywordbsl', foreground: '499caa' },
        // ...другие правила
    ],
    colors: {
        'editor.background': '#1e1e1e',
        'editor.selectionBackground': '#062f4a',
        // ...другие цвета
    }
});
```

### 4. Проверка совместимости токенов

Убедитесь, что все используемые токены корректно определены и совместимы с новой версией:

```javascript
// Проверьте что все токены имеют правильный формат
// Например, для комментариев:
{ token: 'comment.bsl', foreground: '008000' }
```

### 5. Адаптация динамической смены тем

Обновите механизм динамической смены тем:

```javascript
// Динамическое переключение темы (новый подход)
function switchToBSLTheme(themeName) {
    monaco.editor.setTheme(themeName);
}
```

## Проверка и отладка

Для проверки корректности работы подсветки синтаксиса:

1. **Визуальная проверка:**
   - Проверьте подсветку для всех типов токенов: ключевые слова, комментарии, строки, числа и т.д.
   - Проверьте все поддерживаемые темы

2. **Отладка токенизации:**
   - Используйте функцию `debugTokenization` для анализа токенизации конкретного кода
   - Проверьте консоль на наличие ошибок токенизации

3. **Анализ производительности:**
   - Оцените скорость токенизации большого файла
   - Сравните производительность до и после адаптации

## Особенности для языка BSL

При адаптации системы подсветки для BSL учитывайте:

1. **Двуязычность:**
   - BSL поддерживает ключевые слова на русском и английском языках
   - Все ключевые слова должны корректно подсвечиваться в обоих вариантах

2. **Специфичные конструкции:**
   - Процедуры и функции с параметрами
   - Условные конструкции и циклы
   - Директивы компилятора (#Если, #КонецЕсли и т.д.)

3. **Отметки goto:**
   - Поддержка подсветки меток перехода (~МеткаПерехода:)

## Особенности для режима запросов

При адаптации системы подсветки для режима запросов:

1. **Переключение между режимами:**
   - Обеспечьте корректную смену правил подсветки при переключении между обычным режимом и режимом запросов
   - Обновите триггеры для определения начала и конца запроса

2. **Специфичные токены запросов:**
   - SQL-подобные ключевые слова (ВЫБРАТЬ, SELECT, ИЗ, FROM и т.д.)
   - Операторы запросов
   - Параметры и выражения в запросах

3. **Вложенные выражения:**
   - Корректная подсветка вложенных выражений в запросах
   - Обработка подзапросов
