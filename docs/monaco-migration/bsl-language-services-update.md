# План обновления языковых сервисов в bsl_language.js

## Общий анализ

При миграции с Monaco Editor 0.20.0 на 0.45.0+ необходимо учесть следующие изменения в API, которые влияют на языковые сервисы:

1. **Интерфейсы провайдеров**: Изменилась сигнатура многих методов провайдеров
2. **Breaking changes**: 
   - Изменились параметры в API подсказок и автодополнения
   - Новые типы для некоторых опций (например, `wordBasedSuggestions` теперь не булево значение, а `'off' | 'currentDocument' | 'matchingDocuments' | 'allDocuments'`)
   - Произошли изменения в API регистрации языковых сервисов

#### Результаты анализа API Monaco Editor 0.45.0+

   - Новые параметры в методе `provideCompletionItems`
   - Поддержка новых типов автодополнения

4. **Другие провайдеры**:
   - Обновленные интерфейсы для CodeLens, определений и форматирования

   - Новые опции для настройки поведения редактора

Эти изменения требуют обновления соответствующих методов в файле bsl_language.js для обеспечения совместимости с новой версией Monaco Editor.

#### Изменения в API автодополнения

В новой версии Monaco Editor (0.45.0+) произошли следующие изменения в API автодополнения:

1. **Изменения в методе `provideCompletionItems`**:
   - Метод теперь должен возвращать объект с полем `suggestions` вместо массива элементов
   - Пример: `return { suggestions: [...] }` вместо `return [...]`
   - Параметр `context` содержит дополнительную информацию о контексте автодополнения

2. **Изменения в структуре элементов автодополнения**:
   - Добавлено поле `range` для указания диапазона замены
   - Обновлены типы и константы для видов элементов автодополнения
   - Добавлена поддержка новых правил вставки (insertTextRules)

3. **Изменения в методе `resolveCompletionItem`**:
   - Изменилась сигнатура метода и ожидаемый возвращаемый тип

4. **Обновленные опции редактора**:
   - Опция `wordBasedSuggestions` теперь принимает значения `'off' | 'currentDocument' | 'matchingDocuments' | 'allDocuments'` вместо булевого значения

#### План обновления провайдера автодополнения

1. Обновить метод `provideCompletionItems`:
   ```javascript
   provideCompletionItems: function (model, position, context, token) {
       resetSuggestWidgetDisplay();
       let bsl = new bslHelper(model, position);
       let completion = bsl.getCompletion(context, token);
       bsl.onProvideCompletion(context, completion);
       // Обернуть результат в объект с полем suggestions
       return { suggestions: completion };
   }
   ```

2. Обновить метод `resolveCompletionItem`:
   ```javascript
   resolveCompletionItem: function (item, token) {
       // Обновленная сигнатура метода
       // Не требуется model и position
       let bsl = new bslHelper(null, null);
       item = bsl.resolveCompletionItem(item);
       return item;
   }
   ```

3. Обновить структуру элементов автодополнения в методе `getCompletion` класса `bslHelper`

#### Изменения в API подсказок при наведении

В новой версии Monaco Editor (0.45.0+) произошли следующие изменения в API подсказок при наведении:

1. **Изменения в методе `provideHover`**:
   - Метод по-прежнему принимает параметры `(model, position)`
   - Возвращаемый объект имеет обновленную структуру

2. **Изменения в структуре возвращаемого объекта `Hover`**:
   - Поле `contents` теперь является массивом объектов с полем `value`
   - Добавлена поддержка форматирования Markdown в содержимом подсказок
   - Поле `range` теперь должно быть объектом типа `monaco.Range`

3. **Улучшенная поддержка Markdown**:
   - Возможность использовать синтаксис Markdown для форматирования текста
   - Поддержка блоков кода с подсветкой синтаксиса

#### План обновления провайдера подсказок

1. Обновить метод `provideHover`:
   ```javascript
   provideHover: function (model, position) {                    
       let bsl = new bslHelper(model, position);
       bsl.onProvideHover();
       if (!ctrlPressed) {                        
           // Получить подсказку в новом формате
           return bsl.getHover();
       }
       else {
           return null;
       }
   }
   ```

2. Обновить метод `getHover` класса `bslHelper` для возврата объекта в новом формате:
   ```javascript
   getHover() {
       // Пример обновленного формата
       return {
           range: new monaco.Range(
               this.position.lineNumber,
               this.position.column,
               this.position.lineNumber,
               this.position.column + this.word.length
           ),
           contents: [
               { value: "**" + this.word + "**" },
               { value: this.description || "Нет описания" }
           ]
       };
   }
   ```

3. Обновить форматирование содержимого подсказок с использованием Markdown:
   - Использовать синтаксис Markdown для выделения важной информации
   - Добавить форматированные блоки кода для примеров
