# Событие *EVENT_TAB_CHANGED*

## Назначение

Событие сообщает стороне 1С об изменении текущей вкладки или её позиции в панели.

Оно генерируется после создания вкладки, выбора другой вкладки, выбора предыдущей активной вкладки после
закрытия и закрытия фоновой вкладки, если из-за этого изменился индекс текущей.

Повторный клик по уже выбранной вкладке события не создаёт.

## Параметры

```javascript
{
  title: 'Модуль объекта',
  index: 0
}
```

- `title` — отображаемое название;
- `index` — позиция в панели, начиная с нуля.

Названия вкладок могут совпадать, поэтому для текущего состояния следует учитывать оба поля.
