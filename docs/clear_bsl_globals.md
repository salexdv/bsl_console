# Функция *clearBslGlobals*

## Назначение функции

Полностью очищает справочник глобальных объектов. Корневые разделы сохраняются, но становятся пустыми объектами.

```javascript
clearBslGlobals();
```

После очистки справочник остаётся пустым до перезагрузки редактора. Повторный вызов `filterBslGlobals` не может восстановить удалённые объекты.

## Возвращаемое значение

* **boolean** — `true`, если справочник загружен и очищен; `false`, если справочник ещё не загружен.
