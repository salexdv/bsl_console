# Функция *showInlineSuggestion*

## Назначение функции

Показывает inline-подсказку в текущей позиции редактора. Функция принимает массив текстов, но пока показывает только его первый элемент. Если текст первого элемента содержит переводы строк, первая строка показывается внутри текущей строки, а остальные выводятся ниже в виде дополнительного блока.

## Параметры функции

* **suggestions** - *Array&lt;string&gt; | string*, массив текстов inline-подсказок или JSON-строка с таким массивом. Пока используется только первый элемент массива.

## Пример вызова

```javascript
// Передача JavaScript-массива
showInlineSuggestion([
  ' = Новый Запрос();',
  ' = Новый Массив();'
]);

// Передача JSON-строки с многострочной inline-подсказкой
showInlineSuggestion(
  '[" = Новый Запрос();\\nЗапрос.Текст = \\"ВЫБРАТЬ\\";\\nРезультат = Запрос.Выполнить();"]'
);
```
