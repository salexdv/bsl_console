# Функция *showInlineSuggestion*

## Назначение функции

Показывает inline-подсказки в текущей позиции редактора. Все элементы массива доступны как варианты:
между ними можно переключаться стрелками панели или сочетаниями `Alt+[` / `Alt+]`. Если текст содержит
переводы строк, первая строка показывается внутри текущей строки, а остальные выводятся ниже в виде
дополнительного блока.

При наведении на текст подсказки появляется панель управления. `Tab` принимает активный вариант целиком,
`Ctrl+RightArrow` (`Cmd+RightArrow` на macOS) принимает следующую часть слова, а меню `…` позволяет принять
следующую строку или скрыть подсказку.

## Параметры функции

* **suggestions** - *Array&lt;string&gt; | string*, массив текстов inline-подсказок или JSON-строка с таким массивом.

## Пример вызова

```javascript
// Передача JavaScript-массива
showInlineSuggestion([
  ' = Новый Запрос();',
  ' = Новый Массив();'
]);

// Передача JSON-строки с многострочной inline-подсказкой
showInlineSuggestion(
  '[" = Новый Запрос();\\nЗапрос.Текст = \\"ВЫБРАТЬ\\";\\nРезультат = Запрос.Выполнить();"]'
);
```
