# Функция *showInlineSuggestion*

## Назначение функции

Показывает inline-подсказку в указанной позиции редактора. Если переданный текст содержит переводы строк, первая строка показывается внутри текущей строки, а остальные выводятся ниже в виде дополнительного блока.

## Параметры функции

* **lineNumber** - *number*, номер строки, в которой нужно показать inline-подсказку
* **column** - *number*, номер колонки, начиная с которой нужно показать inline-подсказку
* **text** - *string*, текст inline-подсказки

## Пример вызова

```javascript
// Показ однострочной inline-подсказки
showInlineSuggestion(15, 13, ' = Новый Запрос();');

// Показ многострочной inline-подсказки
showInlineSuggestion(
  15,
  13,
  ' = Новый Запрос();\nЗапрос.Текст = "ВЫБРАТЬ";\nРезультат = Запрос.Выполнить();'
);
```
