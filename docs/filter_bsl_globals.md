# Функция *filterBslGlobals*

## Назначение функции

Фильтрует встроенный справочник глобальных объектов, используемый подсказками BSL.

По умолчанию остаются только объекты, перечисленные в массиве `paths`:

```javascript
filterBslGlobals([
  "globalfunctions.Base64Значение",
  "globalfunctions.Base64Строка",
  "classes.ТабличныйДокумент"
]);
```

Если второй параметр равен `true`, перечисленные объекты удаляются, а остальные сохраняются:

```javascript
filterBslGlobals(["classes.ТаблицаЗначений"], true);
```

Для вызова из 1С массив передаётся в виде JSON-строки:

```javascript
filterBslGlobals('["globalfunctions.Base64Значение", "classes.ТабличныйДокумент"]');
```

Формат пути: `имяКорневогоРаздела.имяОбъекта`. Неизвестные пути игнорируются. Фильтрация изменяет текущий справочник непосредственно: удалённые объекты нельзя восстановить повторным вызовом функции. Полный справочник восстанавливается только после перезагрузки редактора.

## Параметры функции

* **paths** — *массив строк или JSON-строка*, пути выбранных объектов
* **exclude** — *boolean*, необязательный параметр; при `true` указанные объекты исключаются

Повторный вызов применяется к уже отфильтрованному справочнику.

Если JSON некорректен или содержит не массив, функция возвращает `false` и не изменяет справочник.

## Возвращаемое значение

* **boolean** — `true`, если справочник загружен и операция выполнена; `false`, если справочник ещё не загружен.
