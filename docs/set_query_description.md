# Функция *setQueryDescription*

## Назначение функции

Показывает примечания подзапросов пакета запросов: серый однострочный текст у правого края
строки — там, где строка кода заканчивается, до минимальной карты (если она включена).
Работает только в режимах языка запросов ([`setLanguageMode('bsl_query')`](set_language_mode.md))
и языка СКД (`setLanguageMode('dcs_query')`).

Подзапросы определяются так же, как раскраска разделителей по опции
[`renderQueryDelimiters`](set_option.md): строками, целиком состоящими из `;` с окружающими
пробелами. Примечание с индексом `i` выводится на строке разделителя `i`; примечание последнего
подзапроса (индекс равен числу разделителей) — на последней строке запроса, если после
последнего `;` есть текст.

Пример:

```
ВЫБРАТЬ Товары.Ссылка ИЗ Справочник.Товары КАК Товары          → подпись индекса 0
;                                                               ← здесь, у правого края
ВЫБРАТЬ Остатки.Количество ИЗ РегистрНакопления.ТоварыНаСкладах
;                                                               ← подпись индекса 1
ВЫБРАТЬ Продажи.Сумма ИЗ РегистрНакопления.Продажи              → подпись индекса 2 (последняя строка)
```

Якоря **пересчитываются при каждом изменении текста**: подпись следует за своим разделителем
при вставке/удалении строк выше, при удалении разделителя индексы последующих подписей
сдвигаются. Повторный вызов из 1С по [событию](modification_event.md) изменения не требуется.

Функция не зависит от опции `renderQueryDelimiters` — подписи рисуются всегда, опция управляет
только подсветкой разделителей цветом. Подписи не кликабельные и не занимают набор
[инлей-хинтов](inlay_hints.md) — механизмы независимы.

## Очистка

- пустой массив или `null` — убирает все подписи;
- `setLanguageMode` в режим, отличный от `bsl_query`/`dcs_query`, — набор забывается;
- полная замена текста модели (`setContent`/`updateText`/`eraseText` или правка, покрывающая
  весь документ) — набор забывается; повторная установка того же текста побайтово — сохраняется.

## Параметры функции setQueryDescription

* **descriptions** - *Array&lt;string&gt; | string | null*, массив примечаний (или JSON-строка с ним):
  индекс элемента равен индексу подзапроса (с нуля). Пустая строка — подзапрос без подписи
  (индекс при этом не сдвигается). Элементы с индексами за пределами числа подзапросов (в том
  числе когда текст кончается на `;`) молча игнорируются.

Невалидная JSON-строка или не-массив возвращает `{errorDescription}` и не меняет текущий набор.
Вызов вне режимов запроса или в режиме сравнения возвращает `false`.

## Пример вызова

```javascript
// Режим языка запросов
setLanguageMode('bsl_query');

setQueryDescription([
    "Товары — справочник номенклатуры",
    "Остатки на складах",
    "Продажи за период"
]);

// Убрать все подписи
setQueryDescription([]);
```

JSON-строка эквивалентна:

```javascript
setQueryDescription('["Товары — справочник номенклатуры", "Остатки на складах", "Продажи за период"]');
```
