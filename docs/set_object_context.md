# Функция *setObjectContext*

## Назначение функции

Функция задаёт контекст объекта, с которым предполагается работа в редакторе, например `"Справочники.Товары"`. После вызова редактор ведёт себя «как в модуле объекта»: в списке подсказок становятся доступны реквизиты объекта, его методы и табличные части.

Подсказки доступны:
* **по Ctrl+Space или просто при наборе** — в общем списке подсказок (например, набор `Запи` показывает метод `Записать`);
* **после точки** для переменной с именем `ЭтотОбъект` или `ThisObject` (без учёта регистра).

Для любой другой переменной после точки объектный контекст не подставляется — если у неё есть собственный тип, работают её собственные подсказки (как раньше).

Если структура запрашиваемого объекта ещё не загружена в редактор, функция инициирует запрос метаданных через событие [`EVENT_GET_METADATA`](get_metadata_event.md).

## Параметры функции

* **metadataName** - *string*, имя объекта метаданных в виде `ВидМетаданных.ИмяОбъекта`, например `"Справочники.Товары"`.

## Возвращаемое значение

* **true** - контекст объекта успешно установлен;
* **объект** вида `{ errorDescription: "..." }` - в случае ошибки (например, неправильное имя метаданных или неизвестный вид метаданных).
* **clearObjectContext** — функция для сброса установленного контекста. Возвращает `true`, если контекст был активен, и `false` в противном случае.

## Примеры вызова функции

```javascript
setObjectContext("Справочники.Товары");
```

После этого в пустом редакторе по Ctrl+Space (или при наборе `Запи`) появятся подсказки `Записать`, `Заблокировать`, свойство `ОбменДанными` и другие реквизиты/методы/табличные части справочника.

Подсказки объекта также появятся после точки для переменной `ЭтотОбъект`:

```javascript
ЭтотОбъект.Записать();
ЭтотОбъект.ОбменДанными.Загрузка = Истина;
```

Сбросить контекст:

```javascript
clearObjectContext();
```

После сброса редактор возвращается к обычному поведению, и подсказки объекта больше не показываются.

## Примечание

* Если реквизиты объекта ещё не загружены, редактор сгенерирует событие [`EVENT_GET_METADATA`](get_metadata_event.md); для построения полной подсказки следует загрузить структуру через [`updateMetadata`](update_metadata.md).
