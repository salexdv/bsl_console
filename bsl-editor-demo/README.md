# Демо BSL-редактора

Демонстрационная версия редактора кода на языке 1С (BSL) на основе Monaco Editor.

## Обновление Monaco Editor

В данной версии выполнена миграция с Monaco Editor 0.20 на Monaco Editor 0.52.
Подробности о миграции можно узнать в файле [MIGRATION.md](MIGRATION.md).

Демо обновленной версии: [https://monaco1cupdate.pages.dev/](https://monaco1cupdate.pages.dev/)

## Запуск

Для запуска демо-версии необходимо:

1. Клонировать репозиторий
2. Открыть файл `index.html` в браузере

Или запустить любой веб-сервер в этой директории, например:

```bash
# Python 3
python -m http.server

# Node.js
npx serve
```

## Особенности

- Подсветка синтаксиса языка 1С
- Автодополнение
- Форматирование кода
- Другие функции редактора Monaco
