# История изменений

## [0.52.0] - 2025-03-22

### Добавлено
- Поддержка Monaco Editor версии 0.52.0
- Подсветка синтаксиса BSL немного пострадала
- Проверена работа на тестовом стенде: https://monaco1cupdate.pages.dev/

### Известные проблемы
- переход в процессе, ещё не до конца завершён, но рабочий с сохранением многих функций с monaco editor 0.20
- есть некоторые проблемы с подсветкой синтаксиса

### Изменено
- Обновлены зависимости до актуальных версий
- Переработан механизм загрузки модулей

### Исправлено
- Различные ошибки в работе автодополнения
- Проблемы с отображением подсказок

## [0.20.0] - Предыдущая версия
