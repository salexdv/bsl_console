# inline-suggestion-syntax-highlighting: управление подсветкой inline-подсказок

## 1. Контекст

Monaco по умолчанию токенизирует текст штатных inline-подсказок и окрашивает его по правилам языка.
Интеграции через мост 1С должны иметь возможность показать ghost text одним цветом темы, не меняя
текст подсказки или языковую грамматику.

## 2. Поведение

1. По умолчанию подсветка синтаксиса inline-подсказок включена, как и до изменения.
2. `setOption('inlineSuggestionSyntaxHighlightingEnabled', false)` отключает токенизацию ghost text
   сразу для открытого обычного редактора.
3. `true` повторно включает токенизацию. Значение сохраняется при пересоздании редактора.
4. Настройка действует на ручные и AI inline-подсказки. В diff-режиме она сохраняется, но визуально
   не применяется, поскольку inline-подсказки там не показываются.

## 3. Контракт

| Опция | Тип | По умолчанию | Описание |
| --- | --- | ---: | --- |
| `inlineSuggestionSyntaxHighlightingEnabled` | `boolean` | `true` | Управляет `inlineSuggest.syntaxHighlightingEnabled` Monaco |

Небулевое значение не применяется: `setOption` возвращает `false`, предыдущее значение сохраняется.
При выключенной токенизации цвет берётся из стандартного `editorGhostText.foreground` активной темы.

## 4. Критерии приёмки

- [x] По умолчанию поведение и цветовая подсветка не изменены.
- [x] `false` делает ручные и AI inline-подсказки однотонными.
- [x] `true` восстанавливает подсветку токенов.
- [x] Небулевое значение отклоняется без изменения настройки.
- [x] Значение переживает пересоздание редактора.

## 5. Вне области

- Настройка отдельного цвета ghost text.
- Изменение формата `showInlineSuggestion` или AI-протокола.
