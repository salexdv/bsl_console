# inline-suggestion-syntax-highlighting: план реализации и решения

## 1. План реализации

1. Добавить значение по умолчанию и применение опции в `editor.js`.
2. Покрыть контракт браузерными тестами и описать опцию в документации.
3. Проверить тестовую и production-сборки, browser mocha и headless smoke.

## 2. Открытые вопросы

Открытых вопросов нет.

## 3. Решения

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-08-21 | Назвать опцию `inlineSuggestionSyntaxHighlightingEnabled` | Имя явно ограничивает область inline-подсказками |
| 2026-08-21 | Значение по умолчанию — `true` | Сохранение обратной совместимости |
| 2026-08-21 | Использовать штатный цвет `editorGhostText.foreground` | Не вводить отдельную настройку темы |
| 2026-08-21 | Отклонять небулевые значения | Не сохранять состояние, которое Monaco молча нормализует иначе |
