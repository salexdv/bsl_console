# Подсказки параметров виртуальных таблиц регистров

Контракт согласован пользователем 2026-11-05 при запросе реализации плана.

## Поведение

В `bsl_query` и `dcs_query` штатное окно Monaco показывает полное имя вызова,
параметры и документацию активного параметра (имя, тип, назначение).
Параметры начинаются с новой строки сигнатуры, чтобы длинное полное имя
не вытесняло активный параметр за правую границу штатного окна.
Поддерживаются русские и английские имена без учёта регистра, без зависимости
от загруженных метаданных. Пробелы, комментарии и переносы в имени вызова допустимы.

Охват: срезы сведений; остатки, обороты и остатки с оборотами накопления;
остатки, обороты, остатки с оборотами, обороты Дт/Кт и движения с субконто
бухгалтерии; данные графика, фактический период действия и
`База<ИмяБазовогоРегистра>` расчёта. Таблица хранения `Субконто` параметров не имеет.
Бухгалтерские обороты имеют варианты с корреспонденцией и без неё; по умолчанию
показывается вариант с корреспонденцией, доступны оба варианта.

Подсказка вызывается штатно на `(`, `,` и через `triggerSigHelp()`.
При вводе `(` после имени виртуальной таблицы встроенное автодополнение
не открывает список метаданных поверх сигнатуры. Пользовательские дополнения
сохраняют приоритет; ручной вызов дополнений остаётся доступным.
Вложенные вызовы, строки и комментарии не искажают счёт аргументов.
После закрытия вложенного вызова восстанавливается внешний контекст.
Неизвестные таблицы и лишние аргументы не получают встроенной подсказки.
Пользовательские сигнатуры приоритетны; `disableNativeSignatures` отключает встроенные.
Мост, события и BSL-строки запросов не меняются.

## Источник данных

Синтакс-помощник 1С 8.3.27.2342, `shcntx_ru.hbk`, раздел `tables`:
`catalog1/table3,table4`; `catalog8/table11,table12,table13`;
`catalog36/table38,table40,table41,table42,table51`;
`catalog43/table48` (оборот без корреспонденции);
`catalog31/table52,table53,table54`; описания параметров — соседние `params/*.html`.
Имена английских таблиц проверены по этим же страницам. Это сигнатуры языка
запросов, а не методов менеджеров регистров.

## Приёмка

- Все четыре примера пользователя и все перечисленные семейства показывают параметры.
- Порядок и документация параметров соответствуют справке, диапазоны Monaco выделяют нужное имя.
- Оба режима, оба языка, пропуски аргументов, вложения, комментарии и многострочный ввод покрыты тестами.
- Проверены пользовательский приоритет, отключение встроенных подсказок, отсутствие метаданных.
- Пройдены браузерные тесты, production-сборка, ES-floor и smoke моста;
  окно проверено в светлой и тёмной темах.
