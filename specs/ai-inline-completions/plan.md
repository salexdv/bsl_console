# ai-inline-completions: план реализации и решения

## 1. План реализации

1. Добавить изолированный AI inline-provider и unit-тесты его состояния.
2. Подключить provider и cancellation token к существующему inline-контроллеру.
3. Опубликовать опции, callback, события и документацию для 1С.
4. Проверить browser lifecycle, production/single-file сборки и ES2015 floor.

## 2. Открытые вопросы

Нет.

## 3. Решения

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-08-20 | Использовать `provideInlineCompletions` и Promise | Сохраняется lifecycle редактора и отсев устаревших ответов |
| 2026-08-20 | Транспорт — существующий `sendEvent`/публичный callback | Сеть и секреты остаются в 1С |
| 2026-08-20 | Мастер-опция выключена по умолчанию | Полная обратная совместимость |
| 2026-08-20 | Передавать ограниченные prefix/suffix, без streaming | Контролируемый размер моста и один callback на запрос |
