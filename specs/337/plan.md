# 337: план реализации и решения

## 1. План реализации

Реализовать публичные операции непосредственным удалением элементов из `window.bslGlobals`, сохраняя корневые разделы. Не хранить отдельную ссылку на полный справочник. Проверить сборку и существующие тесты.

## 2. Решения

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-08-24 | Использовать `filterBslGlobals(paths, exclude = false)` | Один API покрывает оба сценария: include и exclude |
| 2026-08-24 | Игнорировать неизвестные пути | Фильтр удобен для разных версий справочника и не ломает инициализацию |
| 2026-08-24 | Изменять текущий справочник непосредственно | Не удерживать в памяти отдельную ссылку на полный справочник после фильтрации |
