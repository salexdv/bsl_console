# 343: план реализации и решения

## 1. План реализации

1. Ввести единый токен-aware контекст активного вызова и использовать его во всех режимах.
2. Добавить приоритетный поиск полного ключа с fallback на короткий.
3. Расширить `EVENT_BEFORE_SIGNATURE`, документацию и браузерные тесты.
4. Проверить Node-тесты, browser tests, production-сборку и ES2018 floor.

### Риски и снижение

- Разбор строк и встроенных запросов может отличаться между режимами — покрыть BSL, query и DCS
  отдельными сценариями и использовать текущий токенизатор Monaco 0.55.1.
- Полная токенизация текста до курсора может быть дороже прежней эвристики — выполнять её один раз
  на запрос подсказки и переиспользовать токены для скобки и активного параметра.
- В Monaco 0.55 изменён API поиска парных скобок — не зависеть от `model.bracketPairs`, а разбирать
  активный вызов по токенам текущего языка.

## 3. Решения

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-08-24 | Сохранить короткие ключи как fallback | Обратная совместимость документации и интеграций 1С |
| 2026-08-24 | Полный ключ имеет приоритет | Позволяет задавать контекстную сигнатуру метода |
| 2026-08-24 | Добавить `expression`, сохранив `word` | Расширить событие без ломающего изменения |
| 2026-08-24 | Использовать токены текущего языка | Не считать скобки строк и комментариев вызовами |
| 2026-08-24 | Сохранить ленивую токенизацию hover/completion | Не возвращать устранённые издержки issue #335 |
