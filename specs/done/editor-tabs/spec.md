# editor-tabs: вкладки редактора

## 1. Контекст и проблема

Редактор поддерживает только одну активную документную сессию. Для одновременной работы с несколькими
текстами нужны вкладки, при этом существующий публичный API должен продолжать обращаться к текущей вкладке.

## 2. Область изменений

| Компонент | Тип | Характер изменений |
| --- | --- | --- |
| `src/editor.js` | src | lifecycle нескольких редакторов и публичный API |
| `src/tabs.js`, `src/tabs.css` | src | контроллер и интерфейс вкладок |
| `README.md`, `docs/` | docs | контракт функций, события и опции |

## 3. Поведение

### 3.1. Основной сценарий

1. Исходный редактор регистрируется как вкладка «Основная»; при единственной вкладке панель скрыта.
2. `createTab()` создаёт независимую редактируемую сессию, выбирает её и показывает панель.
3. Клик по вкладке делает её текущей; существующие документные функции работают с ней.
4. Закрытие активной вкладки возвращает последнюю ранее активную.
5. Закрытие последней вкладки заменяет её пустой редактируемой BSL-сессией «Основная».

### 3.2. Состояние

- По вкладкам изолированы модели, undo/redo, курсор и прокрутка, язык, read-only, compare,
  закладки, точки останова, review/decorations и контекст документа.
- Тема, шрифты, minimap, wordWrap, публичные настройки `setOption`, справка, метаданные и сниппеты общие.
- Одинаковые названия допустимы и не используются как идентификаторы.

### 3.3. Закрытие

- Крестик есть у каждой вкладки и может закрыть фоновую вкладку без её выбора.
- `confirmTabClose=false` закрывает сразу.
- `confirmTabClose=true` для крестика и `closeCurrentTab()` показывает диалог с кнопками
  «Закрыть» и «Отмена» независимо от наличия изменений.

## 4. Контракты

### 4.1. Экспортные функции моста

```js
/** Создаёт и выбирает новую вкладку. */
function createTab(title, text, options = { language: 'bsl', readOnly: false }) {}

/** Закрывает текущую вкладку с учётом confirmTabClose. */
function closeCurrentTab() {}

/** Возвращает название и нулевой индекс текущей вкладки. */
function getCurrentTab() {}
```

Поля `options.language` и `options.readOnly` необязательны; их значения по умолчанию — `bsl` и `false`.
`createTab()` и `closeCurrentTab()` ничего не возвращают. `getCurrentTab()` возвращает
`{ title: string, index: number }` в формате параметров `EVENT_TAB_CHANGED`, а до инициализации контроллера —
`null`. Начальный текст новой вкладки не создаёт `EVENT_CONTENT_CHANGED`.

### 4.2. События и опции

| Событие / поле | Направление | Payload | Описание |
| --- | --- | --- | --- |
| `EVENT_TAB_CHANGED` | JS → 1С | `{ title, index }` | Текущая вкладка или её индекс изменились; индекс начинается с нуля |
| `confirmTabClose` | опция | `boolean` | Включает подтверждение закрытия; по умолчанию `false` |

`EVENT_TAB_CHANGED` создаётся после `createTab`, выбора другой вкладки, выбора MRU-вкладки после закрытия
и изменения индекса текущей вкладки. Повторный выбор текущей вкладки события не создаёт.

### 4.3. Сборка

Новые исходники входят в обычную и single-file webpack-сборки. Итоговый код сохраняет ES2015-floor и
не добавляет внешних ресурсов или зависимостей.

## 5. Критерии приёмки

- [x] Новые функции доступны через `window` / `defaultView`.
- [x] `getCurrentTab()` возвращает название и нулевой индекс текущей вкладки.
- [x] Текст и документное состояние не протекают между вкладками.
- [x] Compare и закрытие вкладок не оставляют Monaco-моделей и редакторов.
- [x] Подтверждение закрытия работает для API и крестика.
- [x] `EVENT_TAB_CHANGED` содержит название и нулевой индекс.
- [x] Старый публичный API продолжает работать при одной вкладке.
- [x] Обычная и single-file сборки проходят проверки ES2015 и Blob-worker.

## 6. Вне области

- Перетаскивание, переименование и программный выбор вкладки.
- Горячие клавиши навигации.
- Индикатор несохранённых изменений и отдельное событие закрытия.
