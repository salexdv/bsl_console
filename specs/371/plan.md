# 371: план реализации и решения

## 1. План реализации

1. Перенести контракт `labelLink`/`valueLink` и документацию из `develop_0_20`.
2. Адаптировать DOM-реализацию TreeView к ES-модулю и webpack-резолверу иконок текущей ветки.
3. Перенести безопасный текстовый вывод Review без изменения его JSON-контракта.
4. Проверить XSS-сценарии, production/test-сборки и браузерные тесты.

### Риски и снижение

- Механический cherry-pick конфликтует с текущей архитектурой Monaco 0.55: изменения переносятся
  по поведению с сохранением `export default` и функции `resolveTreeIcon`.
- Замена строкового HTML на `DocumentFragment` меняет внутренний результат `parseData`, поэтому
  все операции добавления и замены переводятся на DOM API одновременно.
