# 371: Безопасный вывод TreeView

> Issue: #371. Связанное исправление безопасного вывода Review: #370.

## 1. Контекст и проблема

Данные дерева переменных поступают из 1С и ранее включались в HTML-шаблон без экранирования.
Значения `label`, `value`, `type`, `path`, `class` и `icon` могли изменить DOM дерева и выполнить
HTML-код. Сообщения, авторы и даты замечаний Review имели аналогичную проблему при выводе через
`innerHTML`.

## 2. Область изменений

| Компонент | Тип | Характер изменений |
| --- | --- | --- |
| TreeView | src | Построение дерева DOM-операциями и структурированные ссылки |
| Review | src | Вывод пользовательских данных как текста |
| Документация TreeView | доки | Описание безопасного формата данных |

## 3. Поведение

- Текстовые поля узла отображаются буквально и не интерпретируются как HTML.
- Ссылка в имени или значении задаётся отдельным объектом `labelLink` или `valueLink`.
- CSS-классы принимаются только как набор токенов из букв, цифр, `_` и `-`.
- Имя иконки принимается только из букв, цифр, `.`, `_` и `-`; некорректное имя заменяется
  на `undefined.png`.
- Добавление, замена, раскрытие, закрытие и выбор узлов не бросают исключение при отсутствии цели.
- Данные Review при сохранении и загрузке отображаются как текст.

## 4. Контракты

`showVariablesDescription(variablesJSON)` и
`updateVariableDescription(variableId, variableJSON)` принимают для каждого узла:

```js
{
  label: "Имя",
  labelLink: { href: "адрес", label: "Текст ссылки" },
  value: "Значение",
  valueLink: { href: "адрес", label: "Текст ссылки" },
  type: "Тип",
  path: "Путь",
  class: "final",
  icon: "string.png",
  children: {}
}
```

`labelLink` и `valueLink` необязательны. При их наличии создаётся ссылка, а `label` или `value`
используется как резервный текст. `EVENT_ON_LINK_CLICK` сохраняет существующий payload с именем,
идентификатором и путём переменной, текстом ссылки и `href`.

Формат `getReviewIssues`/`setReviewIssues` и событие `EVENT_ON_REVIEW_CHANGED` не изменяются.

## 5. Критерии приёмки

- [x] Обычные и вложенные узлы корректно добавляются и заменяются.
- [x] Строковый путь и функция-резолвер иконок работают одинаково.
- [x] Структурированные ссылки отправляют прежний `EVENT_ON_LINK_CLICK`.
- [x] HTML в полях TreeView, Review и подписях ссылок не создаёт внедрённых DOM-элементов.
- [x] Сборка остаётся совместима с целевым ES-floor и проходит существующие browser-тесты.

## 6. Вне области

- Изменение формата событий TreeView и Review.
- Изменение разрешённых схем `href`.
- Переработка остальных статических применений `innerHTML` в интерфейсе.
