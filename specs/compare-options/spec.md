# compare-options: настройки отображения режима сравнения

> Issue: нет. Ветка: `feature/compare-options`.

## 1. Контекст и проблема

Режим сравнения всегда показывает значок отмены изменений и скрывает неизмененные области.
Вызывающий код не может управлять этими возможностями Monaco через публичную функцию `setOption`.

## 2. Область изменений

| Компонент | Тип | Характер изменений |
| --- | --- | --- |
| `src/editor.js` | src / мост 1С | учитывать две новые опции при создании и обновлении diff-редакторов |
| `tools/run_tests_headless.js` | тесты | проверить значения по умолчанию и обновление открытого diff-редактора |
| `docs/set_option.md` | доки | описать опции в отдельной секции |
| `docs/compare.md` | доки | описать управление скрытием неизменённых блоков |
| `README.md` | доки | добавить функции в список публичного API |

## 3. Поведение

### 3.1. Основной сценарий

1. Вызывающий код задает `renderMarginRevertIcon` и/или `hideUnchangedRegions` через `setOption`.
2. `compare` применяет значения при создании редактора сравнения.
3. Встроенный редактор `createDiffWidget` использует те же значения.
4. Изменение опций при открытом редакторе сравнения применяется сразу.
5. В режиме сравнения `hideUnchangedBlocks()` устанавливает `hideUnchangedRegions` в `true`,
   а `showUnchangedBlocks()` — в `false`.

### 3.2. Граничные случаи

- Если опция не задана, используется `false`.
- Значения сохраняются при входе в режим сравнения и выходе из него.
- Вне режима сравнения `hideUnchangedBlocks()` и `showUnchangedBlocks()` ничего не делают и не
  изменяют сохранённое значение опции.

### 3.3. Ошибки

- Тип значения не валидируется: как и другие настройки `setOption`, контракт ожидает значение
  документированного типа.

## 4. Контракты

### 4.1. Экспортные функции моста (`window` / `defaultView`)

Сигнатуры `setOption(optionName, optionValue)` и `compare(...)` не меняются. Добавляются экспортные
функции `hideUnchangedBlocks()` и `showUnchangedBlocks()` без параметров и возвращаемого значения.
Список поддерживаемых имён `setOption` расширяется:

| Имя | Тип | По умолчанию | Назначение |
| --- | --- | --- | --- |
| `renderMarginRevertIcon` | `boolean` | `false` | отображать значок отмены изменений |
| `hideUnchangedRegions` | `boolean` | `false` | скрывать неизмененные области |

### 4.2. События (`EVENT_*`) / формат обмена с 1С

Без изменений.

### 4.3. Контракт сборки / доставки

Без изменений. Новые конструкции должны оставаться совместимыми с текущим ES-floor сборки.

## 5. Критерии приёмки

- [x] Обе опции со значением `false` применяются при следующем вызове `compare`.
- [x] Обе опции можно переключить при уже открытом редакторе сравнения.
- [x] `createDiffWidget` учитывает обе опции.
- [x] Без вызова `setOption` обе возможности отключены.
- [x] Документация `setOption` содержит секцию «Управление режимом сравнения», а `compare` ссылается на нее.
- [x] Сборка и доступные автоматические проверки проходят.
- [x] `hideUnchangedBlocks()` скрывает неизменённые области через опцию `hideUnchangedRegions`.
- [x] `showUnchangedBlocks()` показывает неизменённые области через опцию `hideUnchangedRegions`.
- [x] Обе функции вне режима сравнения не изменяют опцию.
- [x] Обе функции перечислены в публичном API и описаны в документации режима сравнения.

## 6. Вне области

- Изменение сигнатуры `compare`.
- Добавление новых событий моста.
- Изменение остальных опций Monaco Diff Editor.
