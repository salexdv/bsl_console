# compare-options: план реализации и решения

Транзиентный спутник [`spec.md`](spec.md).

## 1. План реализации

### Этап 1. Реализация и документация

- Передавать сохраненные значения опций в основной и встроенный diff-редакторы.
- Обновлять уже созданные diff-редакторы при вызове `setOption`.
- Добавить функции `hideUnchangedBlocks()` и `showUnchangedBlocks()`, делегирующие изменение
  `hideUnchangedRegions` функции `setOption` только в режиме сравнения.
- Описать публичный контракт и связать страницы документации.
- Gate: сборка и автоматические проверки проходят, поведение опций подтверждено.

### Риски и снижение

- Разный формат опций Monaco: `renderMarginRevertIcon` принимает `boolean`, а
  `hideUnchangedRegions` — объект `{ enabled: boolean }`. Преобразование централизовано в обвязке.
- Новое значение по умолчанию явно зафиксировано в документации и автоматической проверке.

## 3. Решения

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-07-28 | Сохранять обе опции в существующем `editor_options` | Настройки переживают пересоздание редактора без нового состояния |
| 2026-07-28 | Применять опции сразу к открытым diff-редакторам | `setOption` меняет видимый режим без обязательного перезапуска `compare` |
| 2026-07-28 | Использовать значение `false` по умолчанию | Явное требование владельца |
| 2026-07-28 | Новые функции вызывают `setOption` только при `window.editor.navi` | Вне режима сравнения функции не должны менять сохранённую настройку |
