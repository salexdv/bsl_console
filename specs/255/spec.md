# 255: Расширенное форматирование BSL

> Issue: https://github.com/salexdv/bsl_console/issues/255

## 1. Контекст и проблема

Существующий форматтер исправляет отступы и хвостовые пробелы построчно. Требуется опционально
канонизировать регистр, расставлять пробелы после запятых, разделять операторы, выравнивать группы
присваиваний и возвращать отдельное `Тогда` на строку условия. Преобразования не должны затрагивать
строки, тексты запросов и комментарии.

## 2. Область изменений

| Компонент | Тип | Характер изменений |
| --- | --- | --- |
| `src/bsl_formatter.js` | src | чистый лексический конвейер форматирования |
| `src/bsl_helper.js`, `src/bsl_language.js` | src | адаптеры document/range formatting для Monaco |
| `src/editor.js`, `src/actions.js` | мост/UI | выбор форматирования документа или выделения |

## 3. Поведение

### 3.1. Основной сценарий

1. Вызов `formatDocument()` без аргумента включает все дополнительные преобразования.
2. Каждое преобразование можно независимо выключить значением `false` в JSON-параметре.
3. Опции действуют только на текущий вызов; отсутствующие значения считаются равными `true`.
4. При непустом выделении `formatDocument()` форматирует только полные строки выделенного диапазона.
5. Все изменения применяются одной операцией Monaco и отменяются одним `undo`.

### 3.2. Граничные случаи

- `;`, `,`, ключевые слова и имена внутри строк, запросов и комментариев не изменяются.
- Разделение выполняется только для `;` вне скобок на верхнем уровне оператора.
- Несколько операторов одной строки разделяются после завершающей `;`; точки с запятой внутри
  обычных и многострочных строк, запросов и комментариев не считаются разделителями.
- Выравниваются только соседние простые присваивания без комментариев с одинаковым отступом.
- `Тогда`/`Then` и `Цикл`/`Do` переносятся только с непосредственно следующей строки однострочного
  сбалансированного заголовка `Если`/`ИначеЕсли`, `Пока`, `Для` или `Для Каждого` с английскими
  синонимами.
- `КонецЕсли`/`EndIf` и `КонецЦикла`/`EndDo` изолируются на отдельных строках независимо от
  `formatSplitStatements`.
- При канонизации ключевых слов известное имя класса после `Новый`/`New` берётся из `bslGlobals.classes`.
- Неизвестные и пользовательские имена методов сохраняют исходный регистр.
- При включённой `formatBlankLinesAroundBlocks` объявления функций и процедур, условия, циклы,
  попытки, ветки и окончания обособляются ровно одной пустой строкой с каждой доступной стороны.
- Отдельные `Тогда`/`Then` и `Цикл`/`Do` являются частью многострочного заголовка; пустая строка
  добавляется после маркера, но не внутри заголовка.
- Связанные аннотации и документирующие комментарии не отделяются от следующего объявления.
- Структурные пустые строки не создаются в начале и конце документа или выделения; авторские
  пустые строки между обычными операторами сохраняются.

## 4. Контракты

### 4.1. Экспортные функции моста

Публичная функция принимает необязательную JSON-строку: `formatDocument(optionsJSON?)`. Вызов без
аргумента и вызов с пустым объектом включают все преобразования. Успешный вызов не возвращает
значение; при ошибке валидации возвращается `{ errorDescription }`, а текст не изменяется.

Поддерживаются следующие boolean-поля объекта, по умолчанию равные `true`:

- `formatCanonicalKeywords`;
- `formatCanonicalPlatformNames`;
- `formatSplitStatements`;
- `formatSpaceAfterComma`;
- `formatAlignAssignments`;
- `formatJoinThen`;
- `formatBlankLinesAroundBlocks`.

`formatJoinThen` и `formatBlankLinesAroundBlocks` работают независимо.

Объект может содержать не все поля; отсутствующие поля остаются равными `true`, а неизвестные поля
игнорируются. Для выполнения только базового форматирования все семь полей передаются как `false`.
Некорректный JSON, `null`,
массив, готовый JavaScript-объект и распознанные значения не типа boolean отклоняются. `setOption`
не управляет форматированием.

### 4.2. События

Новые события `EVENT_*` не добавляются.

### 4.3. Сборка и доставка

Форматтер входит в существующий webpack-бандл, не добавляет внешних зависимостей и сохраняет ES-floor
и single-file доставку для старого WebKit поля HTML-документа 1С.

## 5. Критерии приёмки

- [x] Пример issue #255 форматируется ожидаемо при включении всех опций.
- [x] Каждая опция работает независимо; повторный запуск идемпотентен.
- [x] Строки, запросы и комментарии защищены от преобразований.
- [x] Форматирование выделения не изменяет строки вне диапазона и отменяется одним `undo`.
- [x] Структурные границы обособляются ровно одной пустой строкой без изменения литералов и директив.
- [x] Несколько операторов одной строки разделяются без повреждения строковых литералов с `;`.
- [x] Вызов без параметров и пустой JSON-объект включают все семь преобразований.
- [x] Чистые преобразования проверяются отдельной Node-командой `npm run test:formatter`; Monaco provider,
  публичный API, range-formatting и undo остаются в автоматическом Browser Mocha.
- [x] Browser/Mocha, headless smoke, production build и ES-floor проходят.

## 6. Вне области

- Автоматическая вставка пустых строк между произвольными смысловыми группами обычных операторов.
- Полное перестроение длинных выражений и условий по AST.
- Интеграция с внешним BSL Language Server.
