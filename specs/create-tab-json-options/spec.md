# create-tab-json-options: JSON-параметры createTab

## 1. Контекст и проблема

Платформа 1С может передавать в JavaScript-мост только строки. Публичная функция `createTab` принимает
настройки вкладки JavaScript-объектом, поэтому язык и режим «Только просмотр» нельзя задать из 1С.

## 2. Поведение и контракт

`createTab(title, text, options)` принимает в `options` JavaScript-объект или JSON-строку с объектом.
Поддерживаются прежние необязательные поля `language` и `readOnly`; значения по умолчанию — `bsl`
и `false`. Готовые JavaScript-объекты продолжают работать без изменений.

Некорректный JSON, `null`, массив или примитив считаются пустыми настройками. Вкладка создаётся,
функция ничего не возвращает. Неизвестные поля игнорируются. Состав и порядок событий не меняются.

```js
createTab('Запрос', 'ВЫБРАТЬ 1', '{"language":"bsl_query","readOnly":true}');
```

## 3. Критерии приёмки

- [x] JSON-строка задаёт язык и read-only новой вкладки.
- [x] Готовый JavaScript-объект сохраняет прежнее поведение.
- [x] Некорректная строка и JSON не объекта используют настройки по умолчанию.
- [x] Browser Mocha, production-сборка и проверка ES2015/Blob-worker проходят.

## 4. Вне области

- Изменение поддерживаемых полей `options`.
- Добавление ошибок или новых возвращаемых значений `createTab`.
