# inline-suggestion-toolbar: панель управления inline-подсказками Monaco 0.20

## 1. Контекст и проблема

В треке Monaco 0.20 inline-подсказки отрисовываются собственной обвязкой. Публичная функция
`showInlineSuggestion` принимает массив строк, но показывает только первый элемент, а контроллер не умеет
переключать варианты и принимать подсказку частично. В ветке `webpack` эти возможности предоставляет
штатная панель Monaco 0.55.

## 2. Область изменений

| Компонент | Тип | Характер изменений |
| --- | --- | --- |
| `src/editor.js` | src | сессия вариантов, навигация, частичное принятие и content widget |
| `src/decorations.css` | src | оформление панели и меню |
| `src/test.js` | tests | browser-проверки публичного API и панели |
| `docs/` | docs | описание управления несколькими вариантами |

## 3. Поведение

### 3.1. Основной сценарий

1. Все строки, переданные через `showInlineSuggestion`, становятся вариантами одной сессии.
2. При наведении на однострочный или многострочный ghost text появляется панель управления.
3. Стрелки и `Alt+[` / `Alt+]` циклически переключают варианты; панель показывает номер и общее количество.
4. `Tab` или «Принять» вставляет активный вариант целиком.
5. `Ctrl+RightArrow` (`Cmd+RightArrow` на macOS) или «Принять слово» принимает очередную лексическую часть.
6. Меню `…` позволяет принять очередную строку или скрыть подсказку.

### 3.2. Частичное принятие

- Перед словом отдельно принимаются ведущие пробелы и пунктуация; русские и латинские идентификаторы
  принимаются как одно слово.
- Принятие строки включает первый перевод строки. Если перевода нет, принимается весь остаток.
- После частичного принятия остаются только варианты с тем же принятым префиксом.
- Snippet-подсказка принимается целиком. `additionalTextEdits` и `command` выполняются только при полном
  принятии и не повторяются после частичных шагов.

### 3.3. Граничные случаи

- Для единственного варианта стрелки отключены, счётчик показывает `1/1`.
- Пустой массив возвращает `false`; невалидный элемент возвращает `{ errorDescription }` и не показывает
  новую сессию.
- Скрытие, смена модели/позиции, read-only/diff-режим и dispose очищают ghost text, панель, меню и listeners.

## 4. Контракты

### 4.1. Экспортные функции моста

```js
showInlineSuggestion(suggestions)
```

`suggestions` — JavaScript-массив строк или JSON-строка с массивом. Сигнатура и возвращаемые значения не
меняются; изменение поведения состоит в использовании всех элементов массива.

Новых экспортных функций, событий `EVENT_*` и опций редактора не добавляется. Такое же управление
применяется к custom inline provider и AI inline provider.

### 4.2. Сборка и доставка

Панель не использует API Monaco новее 0.20.0. Итоговый JavaScript остаётся на уровне ES2015, а стили и
иконки входят в обычную, single-file и pack-сборки без внешних ресурсов.

## 5. Критерии приёмки

- [x] Все переданные варианты доступны через панель и циклические сочетания клавиш.
- [x] Полное, пословное и построчное принятие работает мышью и клавиатурой.
- [x] Многострочный остаток продолжает отображаться после частичного принятия.
- [x] Панель появляется только при наведении и остаётся открытой при переходе мыши на неё.
- [x] Поведение одинаково для прямых, custom и AI inline-подсказок.
- [x] Browser-тесты, production/single-file сборки и ES2015-проверка проходят.

## 6. Вне области

- Точное копирование внутренних API и DOM Monaco 0.55.
- Streaming, новые настройки видимости панели и новые контракты моста 1С.
