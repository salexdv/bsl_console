# query-object-model: план реализации и решения

## 1. План реализации

Перенести шесть исходных изменений последовательно: базовую модель и hover, игнорирование фигурных
скобок, тестовый корпус, полные имена источников, worker и итоговый сервис. После переноса пройти
browser/corpus-тесты, production и single-file сборки.

### Риски и снижение

- AMD-код исходной ветки адаптируется в ES-модули без публикации новых глобалов.
- Worker собирается существующими `compile-loader` и `blob-url-loader`.
- При ошибке worker сохраняется синхронный fallback.
