# query-object-model: объектная модель запросов и hover псевдонимов

> Issue: #353

## 1. Контекст и проблема

Эвристический разбор текста запроса не даёт устойчиво сопоставлять поля разных ветвей
`ОБЪЕДИНИТЬ`. Для hover нужна tolerant-модель, которая сохраняет структуру и диапазоны даже у
незавершённого запроса во время редактирования.

## 2. Область изменений

| Компонент | Тип | Характер изменений |
| --- | --- | --- |
| Объектная модель запроса | src | Новый tolerant-парсер и позиционный контекст |
| Query hover | src | Поиск псевдонима через модель с эвристическим fallback |
| Worker-сервис | src / сборка | Фоновый разбор во встроенном Blob-worker |
| Тесты и инспектор | тесты | Browser/corpus-тесты и визуальный просмотр модели |

## 3. Поведение

### 3.1. Основной сценарий

1. Текст модели `bsl_query` разбирается после переключения языка и изменений.
2. Hover на поле получает контекст позиции из кешированной модели.
3. Для ветви объединения показывается псевдоним соответствующего поля первой ветви.

### 3.2. Граничные случаи

- Парсер принимает русский и английский синтаксис, вложенные и незавершённые запросы.
- Содержимое фигурных скобок не участвует в разборе.
- Устаревший результат worker не заменяет модель новой версии документа.
- При недоступном worker используется синхронный разбор и прежний алгоритм hover.

### 3.3. Ошибки

Ошибки синтаксиса накапливаются в `document.errors` и не прерывают построение доступной части
модели. Ошибка worker логируется и переводит сервис на главный поток.

## 4. Контракты

Публичные функции `window` и события `EVENT_*` не меняются. Внутренний ES-модуль модели
предоставляет `parse(text)` и `attachRuntime(document)`, а runtime-документ — `findNodeAt(offset)`
и `getContextAt(offset)`. Сервис предоставляет `get`, `getCached`, `schedule` и `parseForModel`.

Worker и все его зависимости встраиваются в `console.js` как Blob URL; внешние worker-файлы не
создаются.

## 5. Критерии приёмки

- [ ] Hover показывает псевдоним первой ветви для полей последующих ветвей объединения.
- [ ] Работают параметры, `ВЫБОР/CASE`, вложенные и незавершённые запросы.
- [ ] Custom/immediate hover сохраняют приоритет, эвристический fallback остаётся доступен.
- [ ] Corpus из 300 запросов проходит без исключений и структурных расхождений.
- [ ] Production и single-file сборки не содержат внешнего worker-файла.

## 6. Вне области

- Новые функции моста 1С и события.
- Копирование vendor-файлов Monaco 0.20.
- Использование объектной модели для автодополнения и перехода к определению.
