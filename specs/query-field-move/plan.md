# Перемещение полей: реализация и решения

## Этапы

1. Переиспользовать токенизатор, добавить чистый расчёт перестановки и Node-тесты.
2. Подключить действия для каждого редактора, добавить браузерные проверки.
3. Прогнать тесты модели, браузерные тесты, production-сборку и ES-floor.

## Решения

- План утверждён пользователем 2026-11-05; спецификация переведена в in-progress.
- Перемещать выражения целиком, одно выделение трактовать как блок полей.
- Не расширять AST вложенных источников: находить списки по токенам и глубине скобок.
- Использовать синхронный расчёт по текущему тексту, чтобы быстрые повторные нажатия
  не применяли правки к устаревшему документу.
- Изменение с запятыми применять одной транзакцией Monaco.
- Обрабатывать нажатия в onKeyDown конкретного редактора до всплытия к общему
  контейнеру вкладок: глобальный сервис Monaco иначе выполняет нажатие повторно.
- Отключённые через disableKeyBinding сочетания оставлять существующему мосту.
