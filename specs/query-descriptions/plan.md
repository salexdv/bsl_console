# query-descriptions: план реализации и решения

Транзиентный спутник [`spec.md`](spec.md). Живёт до закрытия задачи; после merge либо удаляется, либо
уезжает в `specs/done/query-descriptions/plan.md` как архив развития. Сюда — то, что мешает читать
стабильный контракт: этапы работ, открытые вопросы, история решений.

Портирование коммита e31162d (ветка `webpack_0_20`, Monaco 0.20) в ветку `webpack` (Monaco 0.55.1):
геометрия правого края идентична (`contentWidth` не вычитает скроллбар, минимап прижат влево
от него — `editorOptions.js`), формула отступа не меняется.

## 1. План реализации

### Этап 1. Модуль и интеграция

- Шаги: `src/query_descriptions.js` (парсинг входа + вычисление якорей + собственный ре-рендер
  декорациями whole-line); хук контроллера в `initEditorEventListenersAndProperies`;
  `window.setQueryDescription`; пересчёт в `onDidChangeModelContent` (с детектом полной замены
  текста — forget); сброс набора в `setLanguageMode`; стили `.bsl-query-desc` в
  `src/decorations.css`.
- Gate: ручная проверка в `npm run debug` (режимы `bsl_query`/`dcs_query`, правки текста, обе темы,
  минимальная карта вкл/выкл).

### Этап 2. Тесты и доки

- Шаги: кейсы в `src/test.js` (гейт `test:mocha` прогоняет `test.html`/`test_query.html`) —
  якоря по разделителям и последней строке, пересчёт при правках, очистка (пустой массив/null,
  смена режима, полная замена текста), гейты режимов и compare, невалидный вход;
  `docs/set_query_description.md`, строка в `README.md`.
- Gate: `npm run test`, `build:test` + `test:mocha`, `escheck`, `build`.

### Риски и снижение

- Inline-декорации (`afterContentClassName`) участвуют в замере ширины строк Monaco — абсолютное
  позиционирование внутри такой декорации разгоняло бы `scrollWidth` (петля обратной связи).
  Решение: whole-line декорации — они рендерятся в слое overlays (`DecorationsOverlay`), который
  не участвует в замере ширины, а ширина слоя — `max(scrollWidth, contentWidth)`
  (`viewOverlays.js`), т.е. `position:absolute; right:0` внутри декорации даёт правый край области
  кода — до минимальной карты, без влияния на скроллбар.
- Текст подписи нельзя передать декорацией напрямую — динамические CSS-правила
  `content: "..."` с уникальным классом на подпись, по образцу инлей-хинтов на Monaco 0.20
  (ветка `webpack_0_20`); `escapeCssString` — локальный хелпер модуля (в этой ветке
  инлей-хинты нативные, хелпера в `src/inlay_hints.js` нет).
- Декорации сами следуют за текстом; пересчёт нужен для состава (удаление/добавление
  разделителей меняет индексацию) и для якоря последней подписи.

## 3. Решения

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-09-11 | Вход — массив строк (JSON или JSON-строка), без объектов | Простейший контракт по запросу; расширение — несовместимым быть не обязано, отдельные поля не нужны |
| 2026-09-11 | Независимость от опции `renderQueryDelimiters` | Опция управляет только подсветкой; примечания — самостоятельная функция |
| 2026-09-11 | Подписи без событий клика | Задача — отображение; кликабельность не запрошена |
| 2026-09-11 | Очистка: пустой массив/null, смена режима, полная замена текста | Согласовано с пользователем; смена текста целиком делает старые индексы бессмысленными |
| 2026-09-11 | Whole-line декорация в overlays вместо inline afterContentClassName | Не искажает замер ширины строк и ширины скролла (см. риски) |
| 2026-09-11 | Интеграционные тесты — в `src/test.js` | `test:mocha` прогоняет `test.html`/`test_query.html`; прецедент — тесты query-params-tooltips |
| 2026-09-11 | Отступ `right` = ширина вертикального скроллбара при включённом минимапе (`onDidLayoutChange` → перерендер) | В Monaco 0.20 минимап прижат влево от скроллбара, а `contentWidth` его не вычитает — без отступа подписи длиннее строки наезжали бы на карту (~14px); проверено headless-замером геометрии |
| 2026-09-11 | Динамическое правило content — селектор с двумя классами (`.bsl-query-desc.<уникальный>`) | Порядок инжекта style-loader и styleNode не гарантирован; специфичность (0,2,0) стабильнее перестановок |
| 2026-09-11 | zIndex декорации подписи — 100 (поверх подсветки `query-delimiter` с zIndex 0) | В overlays-строке DOM-порядок = стек: без zIndex фон подсветки разделителей (`renderQueryDelimiters`) рендерился поверх текста подписи |
| 2026-09-11 | Кегль подписи 0.85em, отступ от края 8px (`QUERY_DESCRIPTION_RIGHT_PADDING`) | Замечания по итогам ревью: шрифт мельче кода, зазор от края области кода / минимапа 8px; padding из `::after` убран — фон отсутствует, зазор задаётся одним `right` |
| 2026-09-11 | Ширина вертикального скроллбара вычитается всегда, при любом состоянии минимапа (`right = verticalScrollbarWidth + 8`) | Замечание ревью: без минимапа подпись наезжала на видимый скроллбар — Monaco 0.20 не вычитает его из contentWidth, скроллбар рендерится поверх края контента; с минимапом формула даёт тот же итог (минимап прижат влево от скроллбара). Проверено headless-замером на длинном тексте |
| 2026-09-11 | Порт в `webpack`: `escapeCssString` — локальный хелпер модуля | В этой ветке инлей-хинты нативные (Monaco 0.55), CSS-хелпера в `src/inlay_hints.js` нет |
| 2026-09-11 | Порт в `webpack`: dispose контроллера в `disposeEditorInstance` | Контроллер владеет `<style>`-узлом в `document.head`; без dispose узлы текли бы при переключении/закрытии вкладок |
| 2026-09-11 | Порт в `webpack`: в тестах `layoutInfo.minimap.minimapWidth` | В Monaco 0.55 `minimapWidth` вложен в `layoutInfo.minimap` (в 0.20 был top-level) |
