# monaco-ui-locale: план реализации и решения

Транзиентный спутник [`spec.md`](spec.md).

## 1. План реализации

1. Добавить валидируемую webpack-опцию и alias официальной NLS-таблицы.
2. Подключить alias после полифиллов и до модулей Monaco.
3. Добавить английские команды, документацию и headless-проверку.
4. Собрать и проверить обе локали, single-file, pack, ES-floor и мост.

### Риски и снижение

- Порядок ESM-импортов критичен для старого WebKit: локаль подключается только после `polyfills`.
- Дрейф индексов NLS при обновлении Monaco ловится браузерным smoke-тестом на закреплённой версии 0.55.1.
- Размер русского бандла растёт только на одну выбранную таблицу; alias исключает вторую локаль.
