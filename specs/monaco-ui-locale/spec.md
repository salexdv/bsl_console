# monaco-ui-locale: сборочная локализация интерфейса Monaco

Стабильный контракт выбора языка штатного интерфейса Monaco при сборке bsl_console.

## 1. Контекст и проблема

Monaco 0.55.1 содержит официальные русскую и английскую NLS-таблицы, но без их явного подключения
редактор использует английские fallback-строки. NLS загружается до регистрации действий и виджетов,
поэтому безопасное динамическое переключение языка в готовом редакторе не поддерживается.

## 2. Область изменений

| Компонент | Тип | Характер изменений |
| --- | --- | --- |
| `webpack.config.js` | сборка | выбор официальной NLS-таблицы по локали |
| `src/editor.js`, `src/boot.js` | обвязка | ранний импорт выбранной таблицы |
| `package.json`, README, smoke-тест | доставка / доки | английские команды и проверка локали |

## 3. Поведение

### 3.1. Основной сценарий

1. Без параметров сборки подключается `nls.messages.ru.js`.
2. При `--env monacoLocale=en` подключается английская `nls.messages.js`.
3. Выбранная таблица загружается после полифилла `globalThis`, но до любого модуля Monaco.
4. Локаль действует для основного потока и передаётся штатным механизмом Monaco в worker.

### 3.2. Ошибки

- Любое значение `monacoLocale`, кроме `ru` и `en`, завершает сборку с явной ошибкой.

## 4. Контракты

### 4.1. Экспортные функции моста (`window` / `defaultView`)

Публичный мост не меняется. `switchLang` по-прежнему управляет только языком программных подсказок
BSL и не переключает локаль интерфейса Monaco.

### 4.2. Контракт сборки / доставки

- `npm run build` и `npm run debug` используют русский интерфейс.
- Английский интерфейс доступен через `--env monacoLocale=en` и команды с суффиксом `:en`.
- Обычная, single-file и pack-сборки сохраняют прежний формат артефактов и ES-floor.

## 5. Критерии приёмки

- [x] Сборка без параметра показывает `Принять` / `Принять слово` в inline-панели Monaco.
- [x] Английская сборка показывает `Accept` / `Accept Word`.
- [x] Неизвестная локаль отклоняется конфигурацией webpack.
- [x] Headless-smoke проверяет NLS-таблицу и зарегистрированное inline-действие.
- [x] Single-file и pack остаются самодостаточными, worker получает выбранную NLS.
- [x] Публичные функции `window.*` продолжают работать.

## 6. Вне области

- Динамическое переключение штатного интерфейса Monaco через `switchLang`.
- Добавление локалей, кроме русского и английского.
- Перевод собственного интерфейса bsl_console, не принадлежащего Monaco.
