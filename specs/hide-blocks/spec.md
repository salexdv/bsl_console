# hide-blocks: сворачивание произвольных блоков обычного редактора

Стабильный контракт семантического переноса `hideBlocks` и `showHiddenBlocks` из коммита
`a2d2a3e91e89dfb283d7cff8f37ae87b3354a405` ветки `develop_0_20`.

## 1. Поведение

1. `hideBlocks` сворачивает переданные диапазоны строк только в обычном редакторе.
2. Границы диапазонов ограничиваются моделью; некорректные диапазоны и повторная начальная строка
   пропускаются.
3. Виджет скрытой области раскрывает её, после чего glyph margin позволяет свернуть её повторно.
4. `showHiddenBlocks` раскрывает все области, созданные `hideBlocks`.
5. В режиме сравнения обе функции являются безопасным no-op.
6. Собственный source-token не изменяет штатные hidden areas Monaco; состояние освобождается вместе
   с редактором.

## 2. Контракт моста

```javascript
hideBlocks([
  { startLineNumber: 1, endLineNumber: 18 }
]);

showHiddenBlocks();
```

Обе функции доступны через `window` / `defaultView` и возвращают `undefined`.

## 3. Критерии приёмки

- [x] Функции доступны через мост и работают в обычном редакторе.
- [x] В режиме сравнения функции не изменяют исходную и модифицированную стороны.
- [x] Штатные hidden areas Monaco сохраняются.
- [x] Раскрытие, повторное сворачивание и освобождение ресурсов покрыты тестами.
- [x] Проходят браузерные тесты, production- и single-file-сборки.

## 4. Вне области

- `hideUnchangedBlocks` и любое управление скрытыми блоками diff-редактора.
- Изменение штатного folding или опции `hideUnchangedRegions`.
