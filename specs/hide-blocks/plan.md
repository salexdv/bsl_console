# hide-blocks: план реализации и решения

## 1. План реализации

1. Выделить standalone-контроллер скрытых областей с собственным source-token.
2. Подключить `hideBlocks` и `showHiddenBlocks` к мосту с запретом работы в diff-режиме.
3. Добавить стили, документацию и браузерные тесты.
4. Проверить тестовую, production- и single-file-сборки.

## 2. Открытые вопросы

Нет.

## 3. Решения

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-07-28 | Переносить поведение, а не выполнять cherry-pick | Исходный коммит рассчитан на AMD и Monaco 0.20 |
| 2026-07-28 | Не создавать состояние для subeditor diff-редактора | Обе функции должны работать только в обычном редакторе |
| 2026-07-28 | Использовать отдельный модуль и source-token | Изолировать lifecycle и не затирать native hidden areas |
