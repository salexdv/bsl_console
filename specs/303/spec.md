# 303: История последних строк поиска

> Issue: https://github.com/salexdv/bsl_console/issues/303

## 1. Контекст и проблема

Monaco позволяет переключать ранее введённые строки поиска клавишами, но не показывает их списком.
В standalone-сборке история также не переживает пересоздание HTML-документа, поэтому вызывающему коду
1С нужен явный контракт сохранения и восстановления.

## 2. Поведение

- История содержит не более 10 непустых уникальных строк, новые располагаются первыми.
- Строка добавляется при нажатии `Enter` в поле поиска или при потере им фокуса; повтор переносится в начало.
- Кнопка в виджете поиска открывает список истории. Выбор значения устанавливает его в поле и
  запускает обычный поиск Monaco.
- Список примыкает к нижней границе find-виджета, занимает всю его ширину и использует его цвета,
  рамку, скругление и тень.
- Меню поддерживает мышь, `Стрелка вверх`/`Стрелка вниз`, `Enter` и `Esc`.
- При открытии меню мышью ни один пункт не получает фокус автоматически; навигация с кнопки начинается
  по `Стрелке вниз` с первого пункта и по `Стрелке вверх` с последнего.
- Кнопка отображает только `codicon-history`, без рамки и фона; disabled-состояние не меняет
  геометрию и выравнивание пиктограммы.
- История едина для обычного редактора и обеих сторон редактора сравнения.
- Пробелы, регистр и переводы строк в поисковой строке не преобразуются.

## 3. Публичный контракт

```js
saveSearchHistory(): string
restoreSearchHistory(state): true | { errorDescription: string }
```

- `saveSearchHistory()` возвращает JSON-массив строк от новой к старой.
- `restoreSearchHistory(state)` принимает JSON-массив строк и полностью заменяет историю.
- При восстановлении пустые строки и точные дубли удаляются, список сокращается до 10 элементов.
- Некорректный JSON, значение не-массив или нестроковый элемент возвращает ошибку и не изменяет
  текущую историю.
- Новое событие `EVENT_*` не вводится; постоянным хранением управляет вызывающий код 1С.

## 4. Критерии приёмки

- [ ] В историю не попадают промежуточные значения, которые не подтверждены `Enter` и не потеряли фокус.
- [ ] `Enter` добавляет текущую строку и сразу активирует кнопку истории.
- [ ] Штатная история строки замены продолжает работать.
- [ ] Меню отображает не более 10 значений и выбирает строку поиска.
- [ ] Меню не обрезается фиксированной высотой find-виджета Monaco; каждый отображённый пункт доступен мышью.
- [ ] Сохранение и восстановление работают до первого открытия find-виджета и после перехода в diff.
- [ ] Функции доступны через `defaultView`/`window` во всех форматах сборки.
- [ ] Сборка сохраняет целевой ES-floor и работает в старом WebKit поля 1С.

## 5. Вне области

- История строки замены.
- Самостоятельное хранение истории в `localStorage`.
- Закладки или именованные наборы поисковых выражений.
