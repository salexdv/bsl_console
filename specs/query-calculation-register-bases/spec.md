# Имена базовых регистров в автодополнении запросов

В метаданных регистра расчёта `calcRegs.items.<ИмяРегистра>.bases` содержит массив имён базовых регистров. Массив загружается через существующий `updateMetadata` вместе с остальными данными регистра.

После точки в имени регистра расчёта редактор предлагает таблицу для каждого имени из `bases`. Текст подсказки и вставки совпадают. Редактор добавляет префикс `База` или `Base` в зависимости от языкового режима и использует суффикс из массива без преобразования.

Для `action_period` в списке также доступны `ДанныеГрафика` и `ФактическийПериодДействия` или их английские имена. При `bases: []` базовые таблицы отсутствуют. Если массива `bases` нет, редактор предлагает прежний шаблон `База<ИмяБазовогоРегистра>` или `Base<RegisterName>` с редактируемым именем.

## Критерии приёмки

- Для `Начисления` доступны `БазаНачисления`, `БазаДополнительныеНачисления`, `ДанныеГрафика` и `ФактическийПериодДействия`.
- Для `Удержания` доступна `БазаНачисления`.
- В английском режиме полное имя вставляется с префиксом `Base`.
- Пустой массив и метаданные без массива дают разные списки подсказок.
