# План реализации

План согласован пользователем 2026-11-11 запросом на реализацию.

1. Передать `bases` выбранного регистра в `getRegisterVirtualTables` и сформировать подсказки базовых таблиц для обоих типов регистров расчёта.
2. Проверить подсказки после точки через провайдер запросов и покрыть случаи пустого и отсутствующего массива.
3. Запустить `npm run build:test` и `npm run test:mocha` на ветке `webpack`.
