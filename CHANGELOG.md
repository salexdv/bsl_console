## 0.5.1 (02.08.2026)

### Новое:

* Добавлен список процедур и функций текущего модуля с быстрым переходом к выбранному методу по
  `CTRL+ALT+P`. Новый метод публичного API `getModuleMethods` возвращает
  JSON-описание методов, их параметров и признака экспортности.
* Добавлена навигация по структуре запроса: список временных таблиц и результатов запросов, их
  полей и ветвей `ОБЪЕДИНИТЬ`, а также переход к определениям временных таблиц, полей и псевдонимов.
* Тип переменной определяется по коду: конструктор `Новый`, присваивание другой переменной,
  результат метода или глобальной функции. Раньше подсказка через точку работала только если тип
  пришёл от 1С или пункт подсказки выбирали мышью/Enter — набранный руками код подсказок не получал.
* Подсказка имён ключей структуры и колонок таблицы значений, заданных в коде: набор меняется
  операциями `Вставить`, `Колонки.Добавить`, `Колонки.Вставить`, `Удалить`, `Очистить`. Строка
  таблицы наследует её колонки.
* [Объявление типа комментарием](docs/type_hints.md) в синтаксисе строгой типизации ЕДТ — для
  переменных, тип которых из кода не выводится.
* Опубликована онлайн-версия редактора на GitHub Pages.

### Улучшения:

* Переход к определению пользовательской функции теперь работает, когда её вызов находится внутри
  конструкции языка.
* Сборка формируется в кодировке UTF-8 вместо ASCII.
* В упакованной single-file сборке обновлена библиотека сжатия `pako` до версии 3, благодаря чему сжатая версия работат в linux.

### Исправления:

* Подсказка через точку больше не показывает свойства чужого объекта: после
  `ТЗ.Колонки.Добавить("Имя")` для `ТЗ.` предлагались свойства колонки, и тот же неверный тип
  «прилипал» к следующим переменным ([#305](https://github.com/salexdv/bsl_console/issues/305)).
* `ТаблицаЗначений.Индексы` получило ссылку на тип — подсказка для коллекции индексов не работала.
* В WebKit поля HTML 1С восстановлено перетаскивание ползунков скроллбаров, миникарты и разделителей
  редактора ([#386](https://github.com/salexdv/bsl_console/issues/386)).

## 0.5.0 (30.07.2026)

### Новое:
* Редактор переведен на monaco editor v.0.55.1. В новой редакции консоль может использоваться с платформой 8.3.24+.
* Реализован вывод inline-подсказок, используемых, например, для подсказок с помощью ИИ.
* Добавлена поддержка пользовательских подсказок с собственным генерируемым событием и codicon
* Добавлена возможность скрывать области без изменений в режиме сравнения, а также откатывать изменения.
* Добавлена возможность скрывать произвольные области в обычном режиме редактора
* Появилась всплывающая подсказка псевдонимов полей запросов
* Появилась опциональная подсветка экранированных кавычек внутри строк
* Добавлено форматирование запроса при вставке из буфера обмена
* Добавлена сборка в единый самодостаточный HTML без внешних файлов

### Улучшения:

* Улучшена подсветка парных конструкций Если-ИначеЕсли-Иначе-КонецЕсли и навигация по ним
* Исправлены выявленные ошибки
