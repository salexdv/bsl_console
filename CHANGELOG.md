## 0.5.0 (30.07.2026)

### Новое:
* Редактор переведен на monaco editor v.0.55.1. В новой редакции консоль может использоваться с платформой 8.3.24+.
* Реализован вывод inline-подсказок, используемых, например, для подсказок с помощью ИИ.
* Добавлена поддержка пользовательских подсказок с собственным генерируемым событием и codicon
* Добавлена возможность скрывать области без изменений в режиме сравнения, а также откатывать изменения.
* Добавлена возможность скрывать произвольные области в обычном режиме редактора
* Появилась всплывающая подсказка псевдонимов полей запросов
* Появилась опциональная подсветка экранированных кавычек внутри строк
* Добавлено форматирование запроса при вставке из буфера обмена
* Добавлена сборка в единый самодостаточный HTML без внешних файлов

### Улучшения:

* Улучшена подсветка парных конструкций Если-ИначеЕсли-Иначе-КонецЕсли и навигация по ним
* Исправлены выявленные ошибки


## Версии меньше 0.5.0 выходят только для monaco editor v.0.20.0
